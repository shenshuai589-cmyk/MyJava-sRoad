
### 1.打开文件（open）

> open(name, mode, encoding)

```python
file = open("filename.txt", mode="r", encoding="utf-8")
content = file.read()
file.close()
```

```
name: 是要打开的目标文件名的字符串（可以包含文件所在的具体路径）
mode: 设置打开文件的模式（访问模式）:只读、写入、追加等。
encoding: 编码格式（推荐使用UTF-8）
```

| mode | 含义                                             |
| ---- | ---------------------------------------------- |
| r    | 只读方式打开文件，默认的模式                                 |
| w    | 打开一个文件用于写入，==原有内容会被删除，如果该文件不存在，创建新文件==         |
| a    | 打开一个文件用于追加，==新的内容将会被写入到已有内容之后，如果该文件不存在，创建新文件== |

推荐写法：**使用 `with` 语句**(自动关闭文件,避免忘记 `close()` 导致资源泄漏)
```python
with open("filename.txt", "r", encoding="utf-8") as f: 
	content = f.read() 
	# 离开 with 代码块后，文件自动关闭
```



### 2.读取文件（read \readlines）

#### read( char)

> char表示一次要读的字节长度，默认不写的话表示读完整个文件

```python 
with open("filename.txt", "r", encoding="utf-8") as f:
	f.read(10)
	f.read(20) 
# 注意：这一次read(20)会继read(10)读完之后继续读，而不是从头开始读
```


#### readlines()

> readlines表示一行一行的读，将每一行的数据存储到列表当中

```python
with open("filename.txt", "r", encoding="utf-8") as f:
	list = f.readline() # 读取一行
	list = f.readlines() # 读取全部行，得到列表
	print(list)

# 循环文件行，一次循环得到一行数据
with open("filename.txt", "r", encoding="utf-8") as f:
	for line in f:
		print(f"每一行数据是：{line}")	
```

### 关闭文件(close)

```python
file = open("filename.txt", mode="r", encoding="utf-8")
file.close()
```
