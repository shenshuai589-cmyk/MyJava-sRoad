
### 1.常用的字符串格式化

| 名称  | 用处         |
| --- | ---------- |
| %s  | 常用于字符型的格式化 |
| %d  | 常用于整型的格式化  |
| %f  | 常用于浮点型的格式化 |

### 2.数字精度控制

| 名称  | 格式                   |
| --- | -------------------- |
| m   | 表示控制字符的宽度            |
| n   | 表示控制小数部分的精度，四舍五入     |
| m.n | 表示整个字符的长度是m位，小数部分为n为 |
