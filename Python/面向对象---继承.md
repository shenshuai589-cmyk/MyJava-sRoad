

## 单继承

```python
class Person:
	name = None
	age = None
	
def introduce(self):
	print(f"我的名字叫{name},我今年{age}岁了")
	

class Student(Person):
	grade = None
	
	def myGrade(self):
		Person.introduce()
		print(f"我今年上{grade}年级了")
```


## 多继承

```python
class Car:
	car_name = None
	car_price = None
	
	def run(self):
		print("我可以开")
		
class Light:
	name = None
	age = 3
	
	def light(self):
		print("我可以用来照明")
		
class Person:
	name = None
	age = None
	
def introduce(self):
	print(f"我的名字叫{name},我今年{age}岁了")
	
	
class Master(Car,Light,Person):
	pass
	
# 当多继承时，不同的类中有同样的属性时，会根据最近原则匹配
master = Master()
master.age # light中的3
```



### 复写（类似于java中的重写）

```python
class Person:
	name = None
	
	def move(self):
		print("我光脚走路")
		

class Child(Person):
	name = "买了个包"
	age = 20
	def move(self):
		print("我走路光脚")
```
