
```python
list = [1,2,3]
```

## 列表的特点

### 1. 有序性（Ordered）

列表中的元素按照插入的**顺序严格排列**。每个元素都有固定的索引（位置），可以通过索引准确访问或修改。

- **正向索引**：从 `0` 开始（如 `lst[0]` 表示第一个元素）。
- **反向索引**：从 `-1` 开始（如 `lst[-1]` 表示最后一个元素）。

### 2. 可变性（Mutable）

列表是**可变对象**。创建后可以随时原地（In-place）修改其内容，而无需新建一个列表：

- 随时**添加**（`append`、`insert`、`extend`）
- 随时**删除**（`remove`、`pop`、`clear`）
- 随时**修改**（`lst[0] = 'new_value'`）

### 3. 可容纳异构数据（Heterogeneous）

一个列表里可以同时存放**不同数据类型**的元素，甚至可以嵌套其他复杂对象（如列表、字典、函数、类等）：

Python

```
mixed_list = [10, "Hello", 3.14, True, [1, 2, 3], {"key": "value"}]
```

### 4. 允许重复元素（Duplicates Allowed）

列表中可以存在多个数值或内容完全相同的元素：

Python

```
nums = [1, 2, 2, 3, 1]  # 完全合法
```

### 5. 动态扩容（Dynamic Array）

列表在底层是以**动态数组**的形式实现的：

- 你不需要在初始化时指定列表的大小。
- 当添加新元素导致空间不足时，Python 会自动申请更大的内存空间并完成数据搬移，对开发者完全透明。

### 6. 支持切片操作（Slicing）

可以通过 `[start:stop:step]` 的语法非常高效地获取子列表、翻转列表或按步长截取：

Python

```
nums = [0, 1, 2, 3, 4, 5]
sub = nums[1:4]      # [1, 2, 3]
reverse = nums[::-1] # [5, 4, 3, 2, 1, 0]（翻转列表）
```
