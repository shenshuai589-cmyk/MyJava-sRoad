## Set的特点


### 1. 唯一性（去重）—— 最常用特征

集合中的**所有元素都是唯一的**，绝不允许出现重复。如果试图向集合中添加已有的元素，集合会自动忽略。

- **经典应用场景**：给列表或序列高效去重。
    

Python

```
nums = [1, 2, 2, 3, 4, 4, 4]
unique_nums = set(nums)
print(unique_nums)  # 输出 {1, 2, 3, 4}
```

### 2. 无序性（Unordered）

集合中的元素**没有固定的顺序**：

- **不支持索引访问**：无法执行 `s[0]` 或 `s[-1]`，会抛出 `TypeError`。
    
- **不支持切片操作**：无法执行 `s[1:3]`。
    
- **遍历顺序不确定**：多次打印或遍历集合，输出的元素顺序可能是随机的。
    

### 3. 可变性与元素的“可哈希”约束

集合本身是**可变对象**（可以随时添加 `add()` 或删除 `remove()` 元素），但**集合内部存储的元素必须是不可变类型（可哈希 Hashable）**：

- **合法元素**：数字、字符串、元组（内部不含列表）。
    
- **非法元素**：列表、字典、其他集合（这些不可哈希，存入会抛出 `TypeError: unhashable type`）。
    

### 4. 高效的查找性能 —— $O(1)$ 时间复杂度

集合底层基于哈希表（Hash Table）实现：

- 使用 `x in my_set` 判断元素是否存在时，时间复杂度为 **$O(1)$**（常数时间）。
    
- 相比于列表（List）的 $O(n)$ 全盘扫描，在海量数据中进行查找或去重时，集合的性能极高。
