t1 = tuple(1,2,3,4)

## 元组的特点

### 1. 不可变性（Immutable）—— 最核心特征

元组一旦被创建，其**长度和包含的元素引用就无法修改**：

- 无法**添加**元素（没有 `append`、`insert` 等方法）。
    
- 无法**删除**元素（没有 `pop`、`remove` 等方法）。
    
- 无法**修改**元素（执行 `tup[0] = 100` 会直接报错 `TypeError`）。
    

> **注意（浅不可变性）**：如果元组内部包含了可变对象（如列表），那么该可变对象内部的内容是**可以被修改**的：
> 
> Python
> 
> ```
> tup = (1, 2, [3, 4])
> tup[2][0] = 99  # 合法！tup 变为 (1, 2, [99, 4])
> ```

### 2. 有序性（Ordered）与索引访问

与列表相同，元组中的元素严格按照插入顺序排列，同样支持：

- **正向与反向索引**：`tup[0]`、`tup[-1]`。
    
- **切片操作**：`tup[1:3]` 会返回一个新的子元组。
    

### 3. 可容纳异构数据与允许重复

- 可以同时存放任意数据类型（整数、字符串、列表、字典、甚至其他元组）。
    
- 允许存在完全相同的重复元素。
    

### 4. 占用内存更小、性能更高

由于元组是不可变的，Python 在底层对它的内存分配进行了优化：

- **空间效率高**：同等数据量下，元组占用的内存空间比列表小。
    
- **访问速度更快**：元组的创建和遍历速度通常略快于列表。
    

### 5. 可作为字典的键（Key）或集合（Set）的元素

在 Python 中，字典的键和集合的元素必须是**可哈希的（Hashable）**（即不可变类型）：

- **列表**：可变，无法作为字典的键或集合的元素。
    
- **元组**：不可变（只要元组内部不包含列表等可变对象），**可以**作为字典的 Key 或存储在 Set 中。
    

Python

```
# 用元组表示坐标作为字典的键
locations = {(31.23, 121.47): "Shanghai", (39.90, 116.40): "Beijing"}
```

### 6. 支持自动解包（Unpacking）

元组非常适合用于多变量赋值与函数多返回值：

Python

```
# 变量解包
x, y, z = (10, 20, 30)

# 函数返回多个值（本质上返回的就是一个元组）
def get_user():
    return "Alice", 25  # 等价于 return ("Alice", 25)

name, age = get_user()
```

### ⚠️ 使用元组的易错点（单元素元组）

定义只包含**一个元素**的元组时，**必须在元素后面加逗号 `,`**，否则 Python 会将其识别为普通括号运算：

Python

```
t1 = (5)     # int 类型
t2 = (5,)    # tuple 类型（正确写法）
```
