
> Python 是动态类型，类型注解**只做提示，不强制校验**，运行时不会报错；需要第三方库（mypy）做静态检查。Python3.5 + 支持。

## 1. 基础语法

### 变量注解

```
# 变量名: 类型 = 值
a: int = 10
b: str = "hello"
c: float = 3.14
flag: bool = True

# 先声明，后赋值
name: str
name = "张三"
```

### 函数参数 + 返回值注解

```
# def 函数名(参数:类型) -> 返回值类型:
def add(x: int, y: int) -> int:
    return x + y

def say_hello(name: str) -> None:  # None 代表无返回
    print(f"hello {name}")
```

## 2. 容器类型注解

> Python3.9+：直接用 list /dict/set；3.8 及以下需要导入 `typing`

### ✅ Python3.9+（推荐）

```
nums: list[int] = [1,2,3]
user: dict[str, int] = {"age":18}
ids: set[int] = {1,2}
pair: tuple[str, int] = ("小明", 20)
# 不定长元组
t: tuple[int, ...] = (1,2,3,4)
```

### ✅ Python3.8 及更早

```
from typing import List, Dict, Set, Tuple

nums: List[int] = [1,2,3]
user: Dict[str, int] = {"age":18}
pair: Tuple[str, int] = ("小明", 20)
```

## 3. 常用高级类型 typing

```
from typing import Union, Optional, Any

# Union：多种类型之一
def func(x: Union[int, str]) -> None:
    pass
# Python3.10+简写 |
def func2(x: int | str) -> None:
    pass

# Optional：可以是某类型 或者 None
# Optional[int] 等价于 Union[int, None]
def get_num() -> Optional[int]:
    return None

# Any：任意类型，关闭类型提示
data: Any = 123
```

## 4. 面向对象中类型注解

### 实例属性注解

```
class Student:
    # 在 __init__ 外写属性注解
    name: str
    age: int

    def __init__(self, name: str, age: int) -> None:
        self.name = name
        self.age = age

s: Student = Student("Traceback", 20)
```

### 自身类作为返回值（返回本类对象）

Python3.7+ 开头加：`from __future__ import annotations`

```
from __future__ import annotations

class Student:
    def __init__(self,name:str):
        self.name = name
    
    def copy(self) -> Student:
        return Student(self.name)
```

## 5. 类型检查工具 mypy

注解本身不报错，需要 mypy 静态检查代码

```
# 安装
pip install mypy
# 检查py文件
mypy demo.py
```
