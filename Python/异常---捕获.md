基本语法

```
try:
可能发生错误的代码
except:
如果出现异常执行的代码
```


### 捕获指定异常

```python
try:
	print(name)
except NameError as e:
	print("出现了变量未定义的异常")
```


### 捕获多个异常

```python
try:
	print(name)
except (NameError,ZeroDivisionError) as e:
	print("出现了变量未定义的异常")
```
