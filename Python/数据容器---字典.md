## 字典的特点

### 1. 键值对映射（Key-Value Pair）

字典由零个或多个键值对组成：

- **键（Key）**：起到索引或标记的作用。
    
- **值（Value）**：实际存储的数据，可以是任意数据类型（数字、字符串、列表、字典、甚至函数）。
    

Python

```
user_info = {
    "name": "Alice",
    "age": 25,
    "skills": ["Python", "MySQL"]
}
```

### 2. 键的唯一性与“可哈希”限制（Key Constraints）

字典的 **Key** 必须满足以下两个条件：

- **唯一性**：同一个字典中，键不能重复。如果插入了相同的键，后面的值会**覆盖**前面的值。
    
- **可哈希（Hashable / 不可变）**：键必须是不可变数据类型，如**字符串、数字、元组**。
    
    - ❌ **不能作为 Key**：列表（List）、字典（Dict）、集合（Set）（抛出 `TypeError: unhashable type`）。
        
- **Value 无限制**：Value 可以是任意类型，且完全允许重复。
    

### 3. 基于哈希表实现，查找极快 —— $O(1)$ 时间复杂度

字典底层采用**哈希表（Hash Table）**：

- 通过键查找、添加、修改、删除对应的值，平均时间复杂度都是 **$O(1)$**（常数时间）。
    
- 无论字典中存了 10 条还是 1000 万条数据，通过 `dict[key]` 或 `key in dict` 查找数据的速度几乎一样快。
    

### 4. 保留插入顺序（Python 3.7+ 官方保证）

- 在 Python 3.6 之前，字典是完全**无序**的。
    
- **从 Python 3.7 开始（官方正式成为标准语言特性）**，字典会**严格保留键值对被插入时的顺序**。当你遍历字典或打印字典时，元素的排列顺序与你存入时的顺序一致。
    

### 5. 可变性（Mutable）

字典属于**可变对象**，支持原地修改：

- **新增/修改**：`d[key] = value`（键存在则覆盖值，不存在则新增键值对）。
    
- **删除**：`del d[key]`、`d.pop(key)`、`d.clear()`。
    

### 6. 丰富且安全的访问与处理方式

字典提供了非常方便的内置 API：

- **安全访问**：使用 `.get(key, default)` 访问时，若 Key 不存在不会引发 `KeyError`，而是返回设定的默认值（如 `None`）。
    
- **快速遍历**：
    
    - `.keys()`：获取所有的键。
        
    - `.values()`：获取所有的值。
        
    - `.items()`：获取所有的 `(Key, Value)` 元组对。
        

Python

```
# 安全获取，防止报错
age = user_info.get("age", 0)

# 经典遍历方式
for key, value in user_info.items():
    print(f"{key}: {value}")
```
