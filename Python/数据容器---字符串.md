## 字符串的特点


### 1. 不可变性（Immutable）—— 最关键特征

字符串一旦被创建，其内容**无法被原地（In-place）修改**：

- 试图对字符串某一位重新赋值（如 `s[0] = 'a'`）会引发 `TypeError`。
    
- 所有字符串方法（如 `.replace()`、`.upper()`、`.strip()`）都不会修改原字符串，而是**返回一个新的字符串**。
    

Python

```
s = "hello"
s.upper()
print(s)  # 输出仍为 "hello"

s = s.upper()  # 必须重新赋值才能保存新字符串
print(s)  # 输出 "HELLO"
```

### 2. 有序性与序列特性（Sequence Type）

字符串本质上是**字符的有序序列**，支持与列表、元组类似的通用序列操作：

- **索引访问**：支持正向（从 `0` 开始）和反向（从 `-1` 开始）索引，如 `"python"[0]` 为 `'p'`。
    
- **切片操作**：支持 `[start:stop:step]`，如 `"hello"[1:4]` 得到 `"ell"`，`"abc"[::-1]` 可高效翻转字符串。
    
- **成员检验**：支持用 `in` 判断子串是否存在，如 `'py' in 'python'` 返回 `True`。
    

### 3. Unicode 编码支持（天然支持多语言）

从 Python 3 开始，所有字符串默认都是 **Unicode 字符串**：

- 可以无缝混合存储中文、英文、Emoji 表情、特殊符号等。
    
- 每个字符（不论是英文字母 `'a'` 还是中文 `'中'`）在字符串长度计算中都计为 **1 个长度**：
    

Python

```
s = "Hi, 中国 😃"
print(len(s))  # 输出 8
```

### 4. 丰富且强大的内置处理方法

Python 为字符串提供了极多高效的内置处理工具：

- **查找与替换**：`find()`、`index()`、`replace()`、`count()`
    
- **分割与连接**：`split()`、`rsplit()`、`join()`（如 `",".join(["a", "b"])` 拼接高效）
    
- **大小写转换**：`upper()`、`lower()`、`title()`、`capitalize()`
    
- **去除空白与格式化**：`strip()`、`lstrip()`、`rstrip()`、`startswith()`、`endswith()`
    

### 5. 多样的文本表示与格式化语法

Python 提供了灵活的字面量表示与格式化机制：

- **单/双/三引号**：支持 `'...'` 和 `"..."`；三引号 `'''...'''` 或 `"""..."""` 支持直接编写**多行文本**。
    
- **原始字符串（Raw String）**：加 `r` 前缀禁用转义，如 `r"C:\users\name"`，常用于正则表达式与文件路径。
    
- **格式化输出**：
    
    - **f-string（推荐）**：`f"Name: {name}, Age: {age}"`（简洁、直观且性能最佳）。
        
    - `.format()` 方法：`"Name: {}".format(name)`。
        
    - `%` 占位符（传统方式）：`"Name: %s" % name`。
        

### 6. 支持驻留机制（String Interning）优化内存

为了提高性能和节省内存，Python 底层实现了字符串驻留机制：

- 针对某些特定的小字符串（如由字母、数字、下划线组成的较短字面量），Python 会在内存中只保留一份副本。
    
- 相同的字面量在创建时会指向同一块内存地址。
