
一个 URL 的源由三个部分组成：

```
协议 + 域名 + 端口
```

例如：

```
http://localhost:8080
```

和：

```
http://localhost:8081
```

# 一、按照跨域场景分类

## 1. 协议跨域

协议不同。

例如：

```
http://www.example.com
https://www.example.com
```

区别：

```
http
vs
https
```

属于跨域。

---

## 2. 域名跨域

域名不同。

例如：

```
http://a.example.com

http://b.example.com
```

区别：

```
a.example.com
b.example.com
```

属于跨域。

---

## 3. 端口跨域（最常见）

端口不同。

例如：

前端：

```
http://localhost:5173
```

后端：

```
http://localhost:8080
```

区别：

```
5173
8080
```

属于跨域。

前后端分离项目：

```
Vue
localhost:5173

        ↓ ajax

SpringBoot
localhost:8080
```

就是这种。

---

## 4. 子域名跨域

例如：

```
http://user.example.com

http://order.example.com
```

虽然：

```
example.com
```

相同。

但是：

```
user
order
```

不同。

仍然跨域。

---

## 5. IP地址跨域

例如：

```
http://192.168.1.100:8080

http://192.168.1.101:8080
```

IP不同：

```
192.168.1.100
192.168.1.101
```

属于跨域。

---

# 二、按照请求类型分类（开发重点）

浏览器跨域请求分为：

```
简单请求
+
非简单请求
```

---

# 1. 简单请求（Simple Request）

满足：

### 请求方法：

只能：

```
GET
POST
HEAD
```

### 请求头：

只能包含简单请求头：

```
Accept
Accept-Language
Content-Language
Content-Type
```

并且 Content-Type：

只能：

```
text/plain

multipart/form-data

application/x-www-form-urlencoded
```

例如：

```
axios.get(
"http://localhost:8080/user/list"
)
```

流程：

```
浏览器
 |
 | GET请求
 |
 ↓
服务器
 |
 | 返回Access-Control-Allow-Origin
 |
 ↓
浏览器允许
```

---

# 2. 非简单请求（预检请求）

常见：

```
PUT
DELETE
PATCH
```

或者：

请求头包含：

```
Authorization
Content-Type: application/json
```

例如 JWT 登录：

```
axios.get(
"/user/info",
{
 headers:{
   Authorization:"Bearer token"
 }
}
)
```

流程：

第一步：

浏览器发送：

```
OPTIONS /user/info
```

询问：

```
服务器，我可以访问吗？
```

服务器：

返回：

```
Access-Control-Allow-Origin
Access-Control-Allow-Headers
Access-Control-Allow-Methods
```

然后：

真正请求：

```
GET /user/info
```

流程：

```
浏览器

  OPTIONS
      |
      ↓
SpringBoot

  允许

      |
      ↓

  GET请求

      |
      ↓

Controller
```

# 解决跨域的方法

后端开发中主要解决。

---

# 方式一：SpringBoot @CrossOrigin（简单）

在 Controller 上：

```
@RestController
@RequestMapping("/user")
@CrossOrigin
public class UserController {


    @GetMapping("/list")
    public List<User> list(){
        return userService.list();
    }

}
```

表示：

允许所有来源访问。

---

也可以指定：

```
@CrossOrigin(
    origins = "http://localhost:5173"
)
```

只允许 Vue：

```
http://localhost:5173
```

访问。

---

# 方式二：全局配置 CORS（推荐）

实际项目一般不用每个 Controller 写。

创建：

```
config
 └── CorsConfig.java
```

代码：

```
@Configuration
public class CorsConfig {


    @Bean
    public CorsFilter corsFilter(){

        CorsConfiguration config = new CorsConfiguration();


        //允许哪些来源
        config.addAllowedOrigin(
            "http://localhost:5173"
        );


        //允许请求头
        config.addAllowedHeader("*");


        //允许请求方式
        config.addAllowedMethod("*");


        //允许携带Cookie
        config.setAllowCredentials(true);


        UrlBasedCorsConfigurationSource source =
                new UrlBasedCorsConfigurationSource();


        source.registerCorsConfiguration(
                "/**",
                config
        );


        return new CorsFilter(source);
    }
}
```

效果：

```
所有接口
   ↓
允许 Vue 访问
```

---

# 五、Spring MVC方式

如果是传统 SpringMVC：

创建：

```
spring-mvc.xml
```

配置：

```
<mvc:cors>

    <mvc:mapping
        path="/**"
        allowed-origins="http://localhost:8080"
        allowed-methods="GET,POST,PUT,DELETE"/>

</mvc:cors>
```

---

# 六、Spring Security 中的跨域（重点）

如果项目使用：

```
SpringBoot
+
SpringSecurity
+
JWT
```

单纯配置 CorsFilter 可能不生效。

需要开启：

```
@Configuration
public class SecurityConfig {


@Bean
SecurityFilterChain filterChain(HttpSecurity http)
        throws Exception {


    http
        .cors(Customizer.withDefaults())
        .csrf(
            csrf -> csrf.disable()
        );


    return http.build();
}


@Bean
CorsConfigurationSource corsConfigurationSource(){


    CorsConfiguration config =
            new CorsConfiguration();


    config.addAllowedOrigin(
        "http://localhost:5173"
    );


    config.addAllowedHeader("*");


    config.addAllowedMethod("*");


    config.setAllowCredentials(true);


    UrlBasedCorsConfigurationSource source =
            new UrlBasedCorsConfigurationSource();


    source.registerCorsConfiguration(
        "/**",
        config
    );


    return source;
}

}
```

流程：

```
浏览器
 |
 | OPTIONS预检请求
 ↓
SpringSecurity过滤器
 |
 | 判断是否允许跨域
 ↓
Controller
```
