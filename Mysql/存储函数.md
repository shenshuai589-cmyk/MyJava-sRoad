
存储函数是 **存储在数据库服务器中的一段 SQL 程序**，它接收参数，经过处理后**返回一个结果值**。

简单理解：

> **存储过程 = 执行一系列操作，可以返回多个结果，不一定有返回值**  
> **存储函数 = 类似 Java 方法，必须有返回值，可以在 SQL 中直接调用**

例如 Java：

```
public int add(int a, int b){
    return a + b;
}
```

对应 MySQL：

```
CREATE FUNCTION add_num(a INT, b INT)
RETURNS INT
BEGIN
    RETURN a + b;
END;
```

---

# 一、存储函数的特点

|特点|说明|
|---|---|
|存储位置|数据库服务器|
|是否有返回值|必须有|
|调用方式|SQL中直接调用|
|参数|只能输入参数 IN|
|用途|封装计算逻辑|
|是否可以嵌套SQL|可以|

# 二、创建存储函数

基本语法：

```
CREATE FUNCTION 函数名(参数列表)
RETURNS 返回类型
BEGIN

    SQL语句;

    RETURN 返回值;

END;
```

---

例如：

计算两个数字的和：

```
DELIMITER //

CREATE FUNCTION sum_num(a INT,b INT)
RETURNS INT
BEGIN

    DECLARE result INT;

    SET result = a + b;

    RETURN result;

END //

DELIMITER ;
```

---

调用：

```
SELECT sum_num(10,20);
```

结果：

```
30
```

---

# 三、参数

存储函数只有一种参数：

## IN 输入参数

例如：

```
CREATE FUNCTION get_salary(emp_id INT)
RETURNS DOUBLE
BEGIN

    DECLARE sal DOUBLE;

    SELECT salary INTO sal
    FROM employee
    WHERE id = emp_id;

    RETURN sal;

END;
```

调用：

```
SELECT get_salary(1001);
```

# 四、变量声明 DECLARE

存储函数内部变量：

```
DECLARE 变量名 数据类型;
```

例如：

```
DECLARE total INT;
```

赋值：

```
SET total = 100;
```

---

也可以：

```
SELECT COUNT(*)
INTO total
FROM user;
```

例如：

```
CREATE FUNCTION user_count()
RETURNS INT
BEGIN

    DECLARE num INT;

    SELECT COUNT(*)
    INTO num
    FROM user;

    RETURN num;

END;
```

调用：

```
SELECT user_count();
```

返回：

```
1000
```

# 五、存储函数中的流程控制

## 1. IF 判断

语法：

```
IF 条件 THEN

    SQL;

ELSE

    SQL;

END IF;
```

例如：

根据年龄判断：

```
CREATE FUNCTION get_level(age INT)
RETURNS VARCHAR(20)

BEGIN

    IF age >= 18 THEN

        RETURN '成年人';

    ELSE

        RETURN '未成年';

    END IF;

END;
```

调用：

```
SELECT get_level(20);
```

结果：

```
成年人
```

# 六、循环

## WHILE循环

语法：

```
WHILE 条件 DO

    SQL;

END WHILE;
```

例如：

计算1~100的和：

```
CREATE FUNCTION total_num()
RETURNS INT

BEGIN

    DECLARE i INT DEFAULT 1;
    DECLARE total INT DEFAULT 0;


    WHILE i <=100 DO

        SET total = total+i;

        SET i=i+1;

    END WHILE;


    RETURN total;

END;
```

调用：

```
SELECT total_num();
```

结果：

```
5050
```

# 七、存储函数和存储过程区别（面试重点）

|区别|存储函数|存储过程|
|---|---|---|
|关键字|FUNCTION|PROCEDURE|
|返回值|必须有|可以没有|
|参数|只能IN|IN、OUT、INOUT|
|调用方式|SELECT调用|CALL调用|
|适合|计算、查询|业务流程|
|能否用于SQL|可以|不可以|

---

## 示例对比

### 存储函数

```
SELECT get_age(1);
```

### 存储过程

```
CALL update_user(1,'张三');
```

# 面试回答总结

> **MySQL存储函数是存储在数据库中的一段SQL程序，它接收输入参数并返回一个确定值。存储函数必须有返回值，使用SELECT调用，通常用于封装复杂计算逻辑，例如金额计算、数据转换、统计查询。它和存储过程最大的区别是存储函数必须返回值，而存储过程可以执行复杂业务流程。**
