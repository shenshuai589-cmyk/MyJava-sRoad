
## InnoDB 逻辑存储结构

![逻辑结构图](Mysql/image/006-InnoDB逻辑结构图.png)


InnoDB 存储数据的逻辑结构从大到小：

```
Tablespace（表空间）
        |
        ↓
Segment（段）
        |
        ↓
Extent（区）
        |
        ↓
Page（页）
        |
        ↓
Row（行）
```

也就是：

> **表空间 → 段 → 区 → 页 → 行**

这是 MySQL 面试非常常问的结构。

---

# 1. 表空间（Tablespace）

### 最大的逻辑存储单位

一个数据库里面的数据最终都存放在表空间中。

InnoDB 默认：

```
ibdata1
```

系统表空间。

如果开启：

```
innodb_file_per_table=ON
```

那么：

每张表一个独立表空间：

```
user.ibd

order.ibd

product.ibd
```

例如：

```
数据库 campus

        表空间

          |
 ------------------
 |        |        |
user    order   product
.ibd     .ibd     .ibd
```

---

# 2. 段（Segment）

一个表空间里面包含多个段。

常见段：

```
数据段
索引段
回滚段
```

例如：

一张 InnoDB 表：

```
user表空间

      |
      |
 -----------------
 |               |
数据段          索引段
               |
               |
          B+Tree索引
```

注意：

**一个索引就是一个段。**

例如：

user 表：

```
id 主键
name普通索引
age普通索引
```

实际上：

```
user.ibd

 |
 |
 +-- 主键索引段
 |
 +-- name索引段
 |
 +-- age索引段
```

---

# 3. 区（Extent）

一个区由连续的页组成。

大小：

```
1个Extent = 64个Page
```

每个 Page：

```
16KB
```

所以：

```
一个区大小：

64 × 16KB

= 1MB
```

结构：

```
Extent

+--------+
| Page1  |
+--------+
| Page2  |
+--------+
| Page3  |
+--------+

...

+--------+
| Page64 |
+--------+
```

---

# 4. 页（Page）

页是 InnoDB **磁盘管理的最小单位**。

大小：

```
默认16KB
```

MySQL 从磁盘读取数据时：

不是一行一行读。

而是：

```
磁盘

 ↓

读取一个Page

 ↓

里面包含多行数据
```

例如：

```
Page

--------------------------------

id name age

1  张三 20

2  李四 21

3  王五 22

--------------------------------
```

---

# 5. 行（Row）

真正的数据记录。

例如：

```
user表


id    name     age

1     张三      20

2     李四      22

3     王五      25
```

这些就是 Row。

---

# 6. 和 B+树索引结合理解（重点）

InnoDB 主键索引：

```
             Root Page
                  |
        -----------------
        |               |
    Leaf Page       Leaf Page
        |
        |
      数据行
```

注意：

**叶子节点存储完整数据。**

所以：

```
主键索引 = 聚簇索引
```

例如：

```
id=10

查询

select *
from user
where id=10;
```

过程：

```
B+Tree

Root Page

 ↓

非叶子Page

 ↓

叶子Page

 ↓

找到Row
```

# 面试回答版

**Q：说一下 InnoDB 的逻辑存储结构？**

答：

> InnoDB 的逻辑存储结构从大到小依次是表空间、段、区、页、行。表空间是最大的存储单位，一个表空间包含多个段，一个段由多个区组成，一个区默认包含64个连续页，一个页默认大小16KB，是 InnoDB 磁盘管理的最小单位，页中存储具体的数据行。
