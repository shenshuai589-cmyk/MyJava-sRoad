# Agent 开发实习面试 · 3 周备战计划

> 配套文件:`agent-interview-knowledge.md`(知识点清单)
> 原则:每天 **概念 + 动手 + 口述输出** 三件事并行;概念学到能讲清楚为止,时间主要花在 agent-demo 上。
> 每天建议 3~4 小时:1 小时概念 / 2 小时动手 / 30 分钟复述与笔记。

---

## 总览

| 周 | 主题 | 目标 |
|---|---|---|
| 第 1 周 | Tool Calling + Memory + Prompt | demo 能调工具、有记忆、能流式输出 |
| 第 2 周 | RAG + 向量库 + MCP | demo 有完整 RAG,并写过一个 MCP Server |
| 第 3 周 | Agent 编排 + 工程化 + 简历 + 模拟面试 | 能讲清 Agent 原理与工程化,简历与话术成型 |

---

## 时间不够时的取舍

如果只有 2 周,优先级:

**Tool Calling > RAG > Memory > Agent 原理(ReAct)> MCP > 其他**

多 Agent 编排、LangChain4j、Python 框架只做概念了解,不必写代码。

---

## 每日固定动作(建议)

1. 开始前:用 5 分钟回顾昨天的产出
2. 学习中:遇到坑立刻记到"踩坑笔记"(面试素材)
3. 结束前:不看资料,口述今天学的内容 3~5 分钟
4. 代码每天提交到 Git,保持提交记录连续

## 踩坑笔记模板

```
现象:
排查过程:
根本原因:
解决方案:
效果 / 数据:
```

## 面试前最后一天必须能流畅回答

1. Function Calling 的完整流程
2. RAG 的完整链路与调优
3. ReAct 是什么、有什么缺点
4. Agent 怎么防死循环
5. MCP 和 Function Calling 的区别
6. 你项目里遇到的 3 个问题及解决过程
