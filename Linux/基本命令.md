```shell
pwd # 查看当前路径 
ls -l / ls -a # 列出文件 
cd xxx / cd .. # 切换目录 
mkdir test # 创建文件夹 
rm file.txt # 删除文件；
rm -rf 文件夹（慎用！） 
cp src dest # 复制 
mv old new # 移动/重命名 
touch a.txt # 创建空文件
```

### 路径与目录补充

```shell
cd ~ # 回到当前用户家目录
cd - # 回到上一次所在目录
cd / # 切换到根目录
ls -lh # 以易读单位显示文件大小
ls -la # 显示所有文件（含隐藏文件）及详细信息
ls -lt # 按修改时间排序
ls -R # 递归列出子目录
```

> 绝对路径以 / 开头，相对路径相对于当前目录；`.` 表示当前目录，`..` 表示上级目录

> 创建多级目录

```shell
mkdir -p a/b/c # 递归创建多级目录
```

> 删除目录

```shell
rmdir test # 只能删除空目录
rm -r test # 递归删除目录及内容
rm -rf test # 强制递归删除，不提示（慎用！）
rm -i a.txt # 删除前确认
```

> 移动/重命名

```shell
mv a.txt ./Java/ # 移动文件到目录
mv a.txt b.txt # 重命名
mv a.txt b.txt ./Java/ # 移动多个文件
```

### cp命令详细

> 复制文件并重命名

```shell
cp test.txt rename.txt
```

> 复制文件到目标目录

```shell
cp test.txt ./Java/
```

> 复制整个目录

```shell
cp -r Java ./Linux/  # 将Java目录递归复制到Linux目录下
```

> 递归完整备份目录

```shell
cp -a Java ./Python/
```

> 将多个文件复制到同一个目录

```shell
cp a.txt b.txt c.txt ./Java/
```

> 通配符批量复制所有txt

```shell
cp *.txt ./Java/
```

> 覆盖前提示 / 不提示

```shell
cp -i a.txt b.txt # 目标存在时询问是否覆盖
cp -f a.txt b.txt # 强制覆盖
```

### 文件查看

```shell
cat test.txt
cat -n test.txt #显示行号
cat a.txt b.txt #一次读取多个文件

```

> #分页查看文件

```shell
more test.txt (q退出)
less test.txt (space 下一页 b上一页 /hello 向下搜索hello)
```

> less 补充

```shell
# n 查找下一个匹配  N 查找上一个匹配
# ?hello 向上搜索hello
# G 跳到末尾  g 跳到开头
# q 退出
```

#### 查看文件开头

```shell
head test.txt # 默认前10行
head -n 20  test.txt # 查看前20行
```

#### 查看文件末尾

```shell
tail test.txt # 默认后10行
tail -n 100 app.log # 查看最后100行
tail -f app.log # 实时跟踪日志 
tail -F app.log # 文件被轮转/重建后仍继续跟踪
tail -n 100 -f app.log # 先看最后100行并持续跟踪
```

> vim 常用操作（命令模式下）


#### echo 向文件写入内容

```shell

```

#### grep 搜索文件内容

```shell
grep "ERROR" app.log
grep -n "ERROR" app.log #显示行数
grep -i "error" app.log # 忽略大小写
grep -C 5 "ERROR" app.log # 显示匹配行及前后5行
```

> grep 补充

```shell
grep -A 3 "ERROR" app.log # 显示匹配行及其后3行
grep -B 3 "ERROR" app.log # 显示匹配行及其前3行
grep -v "DEBUG" app.log # 反向匹配，排除含DEBUG的行
grep -c "ERROR" app.log # 统计匹配的行数
grep -r "TODO" ./src # 递归搜索目录下所有文件
grep -E "ERROR|WARN" app.log # 扩展正则，匹配多个关键字
```

### 查找文件 find

```shell
find / -name "app.log" # 按文件名查找
find . -name "*.java" # 在当前目录下查找所有java文件
find . -type f # 只查找文件
find . -type d # 只查找目录
find /opt -size +100M # 查找大于100M的文件
find . -mtime -1 # 查找1天内修改过的文件
find . -name "*.log" -mtime +7 -delete # 删除7天前的日志（慎用！）
```

### 查找命令位置

```shell

whereis java # 查看命令的二进制、源码、手册位置
type cd # 查看命令类型（内置命令/外部命令）
```

### 软链接与硬链接 ln

```shell
ln -s /opt/jdk-17 /opt/jdk # 创建软链接（类似快捷方式）
ln a.txt b.txt # 创建硬链接
ls -l # 软链接显示为 l 开头，并带 -> 指向
rm /opt/jdk # 删除软链接（不要加末尾的 /）
```
