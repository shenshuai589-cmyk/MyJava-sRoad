## Linux用户管理

> 查看当前用户名

```shell
whoami
```

> 查看当前用户UID、GID及所属用户组

```shell
id
id tom # 查看指定用户的信息
```

> 创建用户：useradd

```shell
sudo useradd -m tom
sudo useradd -m -s /bin/bash tom # 指定家目录和登录shell
```

> 创建密码

```shell
sudo passwd tom
```

> 切换用户

```shell
su - tom
su - # 切换到root
exit # 退出当前用户
```

> 删除用户

```shell
sudo userdel tom
sudo userdel -r tom # 删除用户及其家目录、邮件文件等相关数据
```

> 修改用户

```shell
sudo usermod -aG developers tom # 将tom追加到developers组（-a 追加，不加会覆盖原有附加组）
sudo usermod -s /bin/bash tom # 修改登录shell
sudo usermod -L tom # 锁定用户
sudo usermod -U tom # 解锁用户
```

> 创建用户组

```shell
sudo groupadd developers
```

> 删除用户组

```shell
sudo groupdel developers
```

> 查看用户所属组

```shell
groups tom
```

> 将用户从组中移除

```shell
sudo gpasswd -d tom developers
```

> 用户与用户组相关文件

```shell
cat /etc/passwd # 用户信息（用户名:x:UID:GID:描述:家目录:shell）
cat /etc/group # 用户组信息
cat /etc/shadow # 加密后的密码（仅root可读）
```

### sudo提权

```shell
sudo command # 以root权限执行命令
sudo -i # 切换为root的交互式shell
sudo visudo # 编辑sudo配置（/etc/sudoers）
sudo usermod -aG sudo tom # Ubuntu/Debian：加入sudo组获得sudo权限
sudo usermod -aG wheel tom # CentOS/RHEL：加入wheel组获得sudo权限
```

## 文件权限

|权限|字母|数值|文件类型常见标识|
|---|---|---|---|
|读|r|4|- :普通文件|
|写|w|2|d : 目录|
|执行|x|1|l : 符号链接|

```shell
ls -l # 查看文件权限
```

> 权限字符串解读

```
-rwxr-xr-- 1 tom developers 1024 Oct 22 10:00 app.sh
│└┬┘└┬┘└┬┘   │    │
│ │  │  │    │    └ 所属组
│ │  │  │    └ 所有者
│ │  │  └ 其他用户权限 r--
│ │  └ 所属组权限 r-x
│ └ 所有者权限 rwx
└ 文件类型 -
```

> 权限对文件和目录的含义

|权限|对文件|对目录|
|---|---|---|
|r|可读取文件内容|可列出目录内容（ls）|
|w|可修改文件内容|可在目录中创建、删除、重命名文件|
|x|可执行文件|可进入目录（cd）|

### 修改文件权限

#### 数字方式

```shell
chmod 777 app.sh # 777 所有者、所属组、其他用户
chmod 755 app.sh # rwxr-xr-x，脚本/目录常用
chmod 644 test.txt # rw-r--r--，普通文件常用
chmod 600 id_rsa # rw-------，私钥文件要求
chmod -R 755 /opt/app # 递归修改目录及其内容
```

#### 字母方式

|字母|含义|
|---|---|
|u|文件所有者|
|g|所属用户组|
|o|其他用户|
|a|所有用户|

```shell
chmod g+w test.txt
chmod +x app.sh # 给所有用户添加执行权限
chmod u+x,g-w,o-r app.sh # 同时修改多项
chmod a=r test.txt # 所有用户只保留读权限
```

### chown修改所有者

```shell
sudo chown tom test.txt # 将文件所有者改为 tom。

sudo chown tom:developers test.txt # 同时修改所有者和所属组

sudo chown -R tom:developers /opt/app # 递归修改目录及其内容

sudo chown :developers test.txt # 只修改所属组
```

### chgrp修改所属组

```shell
sudo chgrp developers test.txt # 将文件所属组修改为 developers
```

### umask默认权限

```shell
umask # 查看当前umask（常见 0022）
# 新建文件默认权限 = 666 - umask = 644
# 新建目录默认权限 = 777 - umask = 755
```

### 常见问题

> Permission denied 排查思路

```shell
ls -l app.sh # 1. 查看文件权限、所有者
id # 2. 确认当前用户及所属组
chmod +x app.sh # 3. 脚本无执行权限时添加
sudo chown -R tom:tom /opt/app # 4. 目录归属不对时修改
```
