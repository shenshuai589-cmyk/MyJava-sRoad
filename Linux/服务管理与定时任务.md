
## systemctl服务管理

```shell
sudo systemctl start nginx # 启动服务
sudo systemctl stop nginx # 停止服务
sudo systemctl restart nginx # 重启服务
sudo systemctl reload nginx # 重新加载配置（不中断服务）
sudo systemctl status nginx # 查看服务状态
sudo systemctl enable nginx # 设置开机自启
sudo systemctl disable nginx # 取消开机自启
systemctl is-active nginx # 查看是否运行中
systemctl list-units --type=service # 列出所有服务
```

### 自定义服务（将Java应用注册为服务）

```shell
sudo vim /etc/systemd/system/myapp.service
```

```ini
[Unit]
Description=My Spring Boot App
After=network.target

[Service]
User=tom
ExecStart=/opt/jdk-17/bin/java -jar /opt/app/app.jar
SuccessExitStatus=143
Restart=on-failure

[Install]
WantedBy=multi-user.target
```

```shell
sudo systemctl daemon-reload # 修改service文件后需要重新加载
sudo systemctl start myapp
sudo systemctl enable myapp
```

### journalctl查看服务日志

```shell
journalctl -u myapp # 查看指定服务的日志
journalctl -u myapp -f # 实时跟踪
journalctl -u myapp -n 100 # 查看最近100行
journalctl -u myapp --since "2026-10-22 10:00:00" # 查看指定时间之后的日志
journalctl -p err # 只看错误级别日志
```

## crontab定时任务

```shell
crontab -e # 编辑当前用户的定时任务
crontab -l # 查看定时任务
crontab -r # 删除所有定时任务（慎用！）
```

> 格式：分 时 日 月 周 命令

|字段|取值范围|
|---|---|
|分|0-59|
|时|0-23|
|日|1-31|
|月|1-12|
|周|0-7（0和7都是周日）|

```shell
0 2 * * * /opt/backup.sh # 每天凌晨2点执行
*/5 * * * * /opt/check.sh # 每5分钟执行一次
0 9 * * 1 /opt/report.sh # 每周一9点执行
30 3 1 * * /opt/clean.sh # 每月1号3:30执行
0 2 * * * /opt/backup.sh >> /opt/backup.log 2>&1 # 将输出记录到日志
```

> 定时任务中的命令建议使用绝对路径，环境变量与登录shell不同

## 环境变量

```shell
env # 查看所有环境变量
echo $PATH # 查看PATH
export MY_VAR=hello # 设置临时环境变量（仅当前终端有效）
unset MY_VAR # 删除变量
```

|文件|作用范围|
|---|---|
|/etc/profile|所有用户，登录时加载|
|~/.bashrc|当前用户，打开终端时加载|
|~/.bash_profile|当前用户，登录时加载|

```shell
vim ~/.bashrc
# 末尾追加：export PATH=$PATH:/opt/tools
source ~/.bashrc # 使修改立即生效
```

### alias别名

```shell
alias ll='ls -lh' # 设置别名（临时）
alias # 查看所有别名
unalias ll # 取消别名
# 写入 ~/.bashrc 可永久生效
```

## Shell脚本基础

```shell
vim deploy.sh
```

```shell
#!/bin/bash
# 变量
APP_NAME="app.jar"
LOG_FILE="/opt/app/app.log"

# 判断
if [ -f "/opt/app/$APP_NAME" ]; then
    echo "文件存在"
else
    echo "文件不存在"
    exit 1
fi

# 循环
for i in 1 2 3; do
    echo "第 $i 次"
done

# 获取命令结果
PID=$(pgrep -f $APP_NAME)
echo "当前PID: $PID"

# 函数
start() {
    nohup java -jar /opt/app/$APP_NAME > $LOG_FILE 2>&1 &
    echo "启动成功"
}
start
```

```shell
chmod +x deploy.sh # 添加执行权限
./deploy.sh # 执行脚本
bash deploy.sh # 也可以直接用bash执行，无需执行权限
```

|特殊变量|含义|
|---|---|
|$0|脚本名称|
|$1|第一个参数|
|$#|参数个数|
|$?|上一条命令的退出状态（0成功）|
|$$|当前进程PID|

|判断|含义|
|---|---|
|-f file|文件存在|
|-d dir|目录存在|
|-z "$a"|字符串为空|
|$a -eq $b|数值相等|
|"$a" = "$b"|字符串相等|
