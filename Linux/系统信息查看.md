## 系统信息查看

### uname 查看系统信息

```shell
uname -a # 查看系统详细信息
uname -r # 查看linux内核版本
uname -m # 查看系统架构
```

### 查看发行版信息

```shell
cat /etc/os-release # 查看发行版名称和版本
lsb_release -a # 查看发行版信息（部分系统需额外安装）
```

### hostname查看主机名

```shell
hostname
hostname -I # 查看本机IP
```

### 查看系统运行时间

```shell
uptime #  20:25:36 up 9 min,  2 users,  load average: 0.13, 0.68, 0.63
```

> load average 依次为 1分钟、5分钟、15分钟的平均负载

### 查看登录用户

```shell
who # 查看当前登录的用户
w # 查看登录用户及其正在执行的操作
last # 查看历史登录记录
```

### top实时查看系统资源

```shell
top
```

|字段|含义|常用快捷键|
|---|---|---|
|PID|进程ID|P （按CPU使用率排序）|
|USER|进程所属用户|M （按内存使用率排序）|
|%CPU|CPU使用率|k （向指定进程发送信号）|
|%MEM|物理内存使用率|q （退出）|
|COMMAND|进程命令名称|1 （显示每个CPU核心）|
|RES|进程使用的常驻物理内存|c （显示完整命令）|
|VIRT|进程使用的虚拟内存大小||

```shell
top -p 1234 # 只监控指定PID的进程
htop # 更友好的top（需安装）
```

### 查看CPU

```shell
lscpu # 查看CPU信息
nproc # 查看CPU核心数
cat /proc/cpuinfo # 查看CPU详细信息
```

### free查看内存

```shell
free -h  # -h 表示以易读单位显示内存大小
cat /proc/meminfo # 查看内存详细信息
```

### vmstat查看系统整体状态

```shell
vmstat 1 5 # 每1秒输出一次，共输出5次
```

### df查看磁盘空间

```shell
df -h
df -h /opt # 查看指定目录所在文件系统的磁盘使用情况
```

### du查看目录占用空间

```shell
du -sh /opt/app

du -h --max-depth=1 /opt

du -h --max-depth=1 /opt | sort -rh | head -10 # 找出占用空间最大的10个目录
```

### 查看磁盘与挂载

```shell
lsblk # 查看磁盘及分区
mount # 查看已挂载的文件系统
sudo mount /dev/sdb1 /mnt # 挂载磁盘
sudo umount /mnt # 卸载
```

## 进程管理

### ps查看进程

```shell
ps # 查看当前终端相关的进程
ps -ef # 查看系统中的进程信息
ps -ef | grep java
ps aux # BSD风格，显示CPU、内存占用
ps aux --sort=-%mem | head -10 # 按内存占用排序，取前10
```

### pgrep按名称查找进程

```shell
pgrep java # 输出java进程的PID
pgrep -af java # 输出PID及完整命令行
```

### kill终止进程

```shell
kill 1234 # 发送SIGTERM(15)，请求进程正常退出
kill -9 1234 # 发送SIGKILL(9)，强制终止（最后手段）
kill -l # 列出所有信号
pkill java # 按名称终止进程
killall java # 按名称终止所有同名进程
```

|信号|编号|含义|
|---|---|---|
|SIGHUP|1|终端断开/重新加载配置|
|SIGINT|2|中断（Ctrl + C）|
|SIGKILL|9|强制终止，无法被捕获|
|SIGTERM|15|正常终止（kill默认信号）|
|SIGSTOP|19|暂停进程|

### 前台与后台运行

```shell
java -jar app.jar & # 后台运行（关闭终端后可能终止）
nohup java -jar app.jar > app.log 2>&1 & # 后台运行，关闭终端后继续运行
jobs # 查看当前终端的后台任务
fg %1 # 将后台任务调到前台
bg %1 # 让暂停的任务在后台继续运行
```

> Ctrl + C 终止前台进程；Ctrl + Z 暂停前台进程

### lsof查看端口与文件占用

```shell
lsof -i:8080 # 查看占用8080端口的进程
lsof -p 1234 # 查看进程打开的文件
```

### 进程相关目录

```shell
ls /proc/1234 # 进程的详细运行信息
```

## Java进程排查

```shell
jps # 查看Java进程
jps -l # 显示主类全名或jar路径
jstack 1234 # 查看线程堆栈（排查死锁、CPU飙高）
jmap -heap 1234 # 查看堆内存使用情况
jmap -dump:format=b,file=heap.hprof 1234 # 导出堆转储
jstat -gc 1234 1000 # 每秒输出一次GC统计
```

> 排查CPU飙高的常见思路

```shell
top # 1. 找到CPU占用高的Java进程PID
top -Hp 1234 # 2. 查看该进程内占用高的线程
printf "%x\n" 5678 # 3. 将线程ID转为16进制
jstack 1234 | grep -A 20 0x162e # 4. 在堆栈中定位对应线程
```

> 部署Java应用的常见流程

```shell
nohup java -jar app.jar --server.port=8080 > app.log 2>&1 &
tail -f app.log # 查看启动日志
ps -ef | grep app.jar # 确认进程是否存在
kill 1234 # 停止应用
```
