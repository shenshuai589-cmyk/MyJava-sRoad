## 包管理

### apt（Ubuntu / Debian）

```shell
sudo apt update # 更新软件源索引
sudo apt upgrade # 升级已安装的软件
sudo apt install nginx # 安装软件
sudo apt install -y nginx # 自动确认
sudo apt remove nginx # 卸载软件（保留配置）
sudo apt purge nginx # 卸载软件并删除配置
sudo apt autoremove # 清理不再需要的依赖
apt search nginx # 搜索软件
apt list --installed # 列出已安装软件
```

### yum / dnf（CentOS / RHEL）

```shell
sudo yum install nginx
sudo yum remove nginx
sudo yum update
sudo yum list installed
yum search nginx
sudo dnf install nginx # 新版本使用dnf，用法与yum基本一致
```

### 本地安装包

```shell
sudo dpkg -i xxx.deb # Debian系安装deb包
dpkg -l | grep nginx # 查看已安装的包
sudo rpm -ivh xxx.rpm # RedHat系安装rpm包
rpm -qa | grep nginx # 查看已安装的包
```

### 更换国内镜像源

```shell
sudo cp /etc/apt/sources.list /etc/apt/sources.list.bak # 修改前先备份
sudo vim /etc/apt/sources.list # 替换为阿里云/清华等镜像地址
sudo apt update
```

## 压缩与解压

### tar

```shell
tar -cvf test.tar Java/ # 打包（不压缩）
tar -zcvf test.tar.gz Java/ # 打包并用gzip压缩
tar -xvf test.tar # 解包
tar -zxvf test.tar.gz # 解压tar.gz
tar -zxvf test.tar.gz -C /opt # 解压到指定目录
tar -tvf test.tar.gz # 只查看压缩包内容，不解压
```

|参数|含义|
|---|---|
|c|创建压缩包|
|x|解压|
|z|使用gzip压缩/解压|
|v|显示过程|
|f|指定文件名（必须放在最后）|
|C|指定解压目录|

### zip / unzip

```shell
zip test.zip a.txt b.txt # 压缩文件
zip -r test.zip Java/ # 压缩目录
unzip test.zip # 解压
unzip test.zip -d /opt # 解压到指定目录
unzip -l test.zip # 查看压缩包内容
```

### gzip

```shell
gzip app.log # 压缩，原文件会被替换为 app.log.gz
gunzip app.log.gz # 解压
```

## 安装JDK并配置环境变量

```shell
tar -zxvf jdk-17_linux-x64_bin.tar.gz -C /opt # 解压到/opt
sudo vim /etc/profile # 编辑全局环境变量
```

> 在 /etc/profile 末尾追加

```shell
export JAVA_HOME=/opt/jdk-17
export PATH=$JAVA_HOME/bin:$PATH
```

```shell
source /etc/profile # 使配置立即生效
java -version # 验证
echo $JAVA_HOME
```
