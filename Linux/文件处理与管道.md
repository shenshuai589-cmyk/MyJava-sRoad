## 管道与重定向

### 管道 |

> 将前一个命令的输出作为后一个命令的输入

```shell
ps -ef | grep java # 查找java进程
cat app.log | grep "ERROR" # 过滤日志
ls -l | wc -l # 统计当前目录文件数量
history | grep ssh # 在历史命令中查找ssh
```

### 重定向

|符号|含义|
|---|---|
|>|标准输出重定向（覆盖）|
|>>|标准输出重定向（追加）|
|2>|错误输出重定向|
|2>&1|将错误输出合并到标准输出|
|&>|标准输出和错误输出一起重定向|
|<|输入重定向|

```shell
ls > list.txt # 将结果覆盖写入文件
ls >> list.txt # 将结果追加到文件
ls /not_exist 2> error.log # 只记录错误信息
java -jar app.jar > app.log 2>&1 # 标准输出和错误输出都写入app.log
command > /dev/null 2>&1 # 丢弃所有输出
```

> /dev/null 是“黑洞”文件，写入的内容会被丢弃

## 文本处理命令

### sort 排序

```shell
sort test.txt # 按字典序排序
sort -n test.txt # 按数值排序
sort -r test.txt # 倒序
sort -k 2 test.txt # 按第2列排序
```

### uniq 去重

```shell
sort test.txt | uniq # 去重（需先排序，uniq只去除相邻重复行）
sort test.txt | uniq -c # 去重并统计每行出现次数
```

### cut 按列截取

```shell
cut -d ',' -f 1 data.csv # 以逗号分隔，取第1列
cut -d ':' -f 1,3 /etc/passwd # 取第1、3列
```

### awk 按列处理文本

```shell
awk '{print $1}' access.log # 打印第1列
awk '{print $1, $3}' access.log # 打印第1、3列
awk -F ':' '{print $1}' /etc/passwd # 指定分隔符为冒号
awk '$9 == 500' access.log # 筛选第9列等于500的行
awk '{sum += $1} END {print sum}' data.txt # 对第1列求和
```

### sed 流编辑器

```shell
sed 's/old/new/' test.txt # 替换每行第一个匹配（不修改原文件）
sed 's/old/new/g' test.txt # 全局替换
sed -i 's/old/new/g' test.txt # 直接修改原文件
sed -n '10,20p' app.log # 打印第10到20行
sed '/^$/d' test.txt # 删除空行
```

### xargs 将输入转为命令参数

```shell
find . -name "*.log" | xargs rm # 批量删除找到的日志
find . -name "*.java" | xargs grep "TODO" # 在所有java文件中搜索TODO
```

### tee 同时输出到屏幕和文件

```shell
java -jar app.jar | tee app.log
```

## 常用日志分析组合

```shell
grep "ERROR" app.log | wc -l # 统计错误行数
grep "ERROR" app.log | tail -n 20 # 查看最近20条错误
awk '{print $1}' access.log | sort | uniq -c | sort -rn | head -10 # 统计访问量前10的IP
cat app.log | grep "2026-10-22" | grep "ERROR" # 查看某天的错误日志
```
