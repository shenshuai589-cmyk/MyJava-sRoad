## 网络信息查看

### 查看IP与网卡

```shell
ip addr # 查看网卡及IP地址（推荐）
ip a # 简写
ifconfig # 旧命令，需安装 net-tools
hostname -I # 只显示本机IP
ip route # 查看路由表
```

### ping测试连通性

```shell
ping www.baidu.com
ping -c 4 www.baidu.com # 只发送4个包（Linux默认会一直ping，Ctrl+C停止）
```

### curl发送HTTP请求

```shell
curl http://localhost:8080/api/hello # GET请求
curl -I http://localhost:8080 # 只查看响应头
curl -X POST -H "Content-Type: application/json" -d '{"name":"tom"}' http://localhost:8080/api/user # POST JSON
curl -o file.zip http://example.com/file.zip # 下载并保存为指定文件
curl -v http://localhost:8080 # 显示详细请求/响应过程
```

### wget下载文件

```shell
wget http://example.com/file.zip
wget -O new.zip http://example.com/file.zip # 指定保存文件名
wget -c http://example.com/file.zip # 断点续传
```

### 查看端口与连接

```shell
ss -tlnp # 查看监听中的TCP端口及对应进程（推荐）
ss -tlnp | grep 8080 # 查看某端口
netstat -tlnp # 旧命令，需安装 net-tools
lsof -i:8080 # 查看占用端口的进程
```

|参数|含义|
|---|---|
|-t|TCP|
|-u|UDP|
|-l|只显示监听状态|
|-n|不解析域名，直接显示数字|
|-p|显示进程信息|

### 测试端口是否可达

```shell
telnet 192.168.1.10 3306
nc -zv 192.168.1.10 3306 # 检测端口是否开放
```

### DNS查询

```shell
nslookup www.baidu.com
dig www.baidu.com
cat /etc/hosts # 本地域名映射
```

## 防火墙

### ufw（Ubuntu）

```shell
sudo ufw status # 查看状态
sudo ufw enable # 开启防火墙
sudo ufw allow 8080 # 放行端口
sudo ufw delete allow 8080 # 删除规则
```

### firewalld（CentOS）

```shell
sudo systemctl status firewalld # 查看状态
sudo firewall-cmd --list-all # 查看当前规则
sudo firewall-cmd --add-port=8080/tcp --permanent # 永久放行端口
sudo firewall-cmd --reload # 重新加载使规则生效
sudo firewall-cmd --remove-port=8080/tcp --permanent # 移除端口
```

> 云服务器还需要在安全组中放行对应端口

## 远程连接

### ssh远程登录

```shell
ssh tom@192.168.1.10 # 使用用户名登录
ssh -p 2222 tom@192.168.1.10 # 指定端口
ssh -i ~/.ssh/id_rsa tom@192.168.1.10 # 指定私钥
exit # 退出远程连接
```

### 免密登录

```shell
ssh-keygen -t rsa # 生成密钥对（~/.ssh/id_rsa 和 id_rsa.pub）
ssh-copy-id tom@192.168.1.10 # 将公钥拷贝到服务器
chmod 700 ~/.ssh # 权限不对会导致免密失败
chmod 600 ~/.ssh/authorized_keys
```

### scp远程拷贝

```shell
scp app.jar tom@192.168.1.10:/opt/app/ # 上传文件
scp -r ./dist tom@192.168.1.10:/opt/web/ # 上传目录
scp tom@192.168.1.10:/opt/app/app.log ./ # 下载文件
scp -P 2222 app.jar tom@192.168.1.10:/opt/app/ # 指定端口（注意是大写P）
```

### rsync增量同步

```shell
rsync -avz ./dist/ tom@192.168.1.10:/opt/web/ # 增量同步目录
```
