# 1. JDBC:
### 1. JDBC的概念
 ```  
 Java DataBase Connectivity (java数据库连接)
 简单的说：Java用来操作数据库（MySQL）的标准接口
 ``` 
### 2. JDBC的作用
 ``` 
JDBC可以完成：
查询数据（SELECT）
插入数据（INSERT）
修改数据（UPDATE）
删除数据（DELETE）
 ```

### 3.JDBC开发核心六步
``` java
// 1.获取连接 
public class Jdbc{
	public static void main(String[] args) throws Exception {
		// 1.注册驱动 (可省略)
        Class.forName("com.mysql.cj.jdbc.Driver");
        // 2.获取连接对象(url,username,password三个形参)
        /*
        url的格式：jdbc:mysql://主机名:端口号/数据库名
		username:用户名
		password:密码
		*/
		Connection conn = DriverManager.getConnection(
		"jdbc:mysql://localhost:3306/mydb_1",  
		"root",  
		"250712"
		);
		// 3.获取执行sql语句的对象
		Statement statement = connection.createStatement();
		// 4.编写sql语句并执行，以及接收返回的结果集
		String sql = "select * from score";  
		ResultSet resultSet = statement.executeQuery(sql);
		
		// 5.处理结果：遍历resultSet结果集
		while (resultSet.next()) {  
		    int studentId = resultSet.getInt("student_id");  
		    String name = resultSet.getString("course");  
		    int score = resultSet.getInt("score");  
		    System.out.println(studentId + "\t" + name + "\t" + score);  
		}
		// 6.释放资源（先开启的后释放）
		resultSet.close();
		statement.close();
		conn.close();
	}
	
} 	

```

### 5. 什么是 SQL 注入

`用户输入恶意SQL，改变原有SQL逻辑 `
### 6. 如何防止 SQL 注入

`使用 PreparedStatement`
### 7. PreparedStatement 为什么安全

`预编译SQL，参数单独传递 `

### 8. JDBC数据插入
``` java
public class JDBCInsert {  
    public static void main(String[] args) throws Exception {  
        JDBCUpdate jdbcUpdate = new JDBCUpdate();  
        jdbcUpdate.testInsert();  
    }  
    public void testInsert() throws Exception {  
        //1.获取连接对象  
        Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/mydb_1","root","250712");  
        //2.预编译SQL  
        PreparedStatement preparedStatement = connection.prepareStatement("insert into score values(?,?,?)");  
		// 3.赋值
        preparedStatement.setInt(1,5);  
        preparedStatement.setString(2,"数学");  
        preparedStatement.setInt(3,90);  
  
        // 4.执行 
        int i = preparedStatement.executeUpdate();  
  
        //5.判断  
        if (i>0){  
            System.out.println("成功");  
        }else{  
            System.out.println("失败");  
        }  
        // 6.释放资源
        preparedStatement.close();  
        connection.close();  
    }  
}
``` 

# 2. JDBC 常见异常总结

# 一、ClassNotFoundException（最常见）

## 异常示例

```java
java.lang.ClassNotFoundException: com.mysql.jdbc.Driver
```

## 出现原因

没有导入 mysql 驱动包 或驱动类名写错

## 解决办法

### 1. 导入 Maven 依赖

```xml
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
    <version>8.0.33</version>
</dependency>
```

### 2. MySQL8 驱动类

```java
com.mysql.cj.jdbc.Driver
```

---

# 二、SQLException（数据库异常）

SQLException 是 JDBC 最核心异常

```java
SQLException
```

所有数据库错误基本都属于这个异常

例如：

- SQL语法错误
    
- 表不存在
    
- 字段不存在
    
- 权限不足 

异常示例

```java
java.sql.SQLException: Table 'test.user' doesn't exist
```

解决方法

检查：

- SQL语句
    
- 表名
    
- 字段名
    
- 数据库名

---

# 三、CommunicationsException（连接数据库失败）

异常示例

```java
Communications link failure
```

出现原因

数据库连接失败

可能原因：

- MySQL没启动
    
- IP地址错误
    
- 端口错误
    
- 数据库名错误

连接字符串示例

```java
jdbc:mysql://localhost:3306/test
```

---

# 四、Access denied（用户名密码错误）

异常示例

```java
Access denied for user 'root'@'localhost'
```

出现原因

用户名或密码错误

解决办法

```java
String username = "root";
String password = "123456";
```

---

# 五、No suitable driver（驱动不匹配）

异常示例

```java
No suitable driver found for jdbc:mysql://localhost:3306/test
```

出现原因

- 没加载驱动
    
- 驱动版本不匹配
    
- URL 写错
    

解决办法

```java
Class.forName("com.mysql.cj.jdbc.Driver");
```

---

# 六、NullPointerException（空指针）

异常示例

```java
NullPointerException
```

出现原因

连接对象为 null

```java
Connection conn = null;
conn.prepareStatement(sql);
```

解决办法

```java
Connection conn = DriverManager.getConnection(...);
```

---

# 七、SQLSyntaxErrorException（SQL语法错误）

异常示例

```java
You have an error in your SQL syntax
```

示例

```sql
select * form user;
```

解决办法

检查 SQL 语法

---

# 八、ResultSet closed（结果集关闭）

异常示例

```java
ResultSet closed
```

出现原因

ResultSet 已关闭仍然使用

```java
rs.close();
rs.next();
```

关闭顺序

```text
ResultSet
Statement
Connection
```

---

# 九、JDBC异常继承结构

```
Throwable
 └── Exception
      └── SQLException
            ├── SQLSyntaxErrorException
            ├── SQLTimeoutException
            ├── SQLIntegrityConstraintViolationException
```

常见异常

| 异常                                       | 说明      |
| ---------------------------------------- | ------- |
| SQLException                             | 所有数据库异常 |
| SQLSyntaxErrorException                  | SQL语法错误 |
| SQLTimeoutException                      | 查询超时    |
| SQLIntegrityConstraintViolationException | 主键冲突    |

---

# 十、JDBC异常最佳处理方式

推荐写法

```java
try {

} catch (SQLException e) {
    e.printStackTrace();
}
```

或者

```java
throws SQLException
```

# 总结

JDBC 常见异常主要分为三类：

## 1. 环境问题

- 驱动未导入
    
- 数据库未启动
    
- URL错误

## 2. 代码问题

- SQL语法错误
    
- 空指针异常

## 3. 数据问题

- 主键冲突
    
- 字段不存在
