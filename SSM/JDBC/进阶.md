
# 1.实体类搭建

### 1.1 实体类的概念

在 JDBC 开发中，**实体类（Entity / POJO）** 用来与数据库表一一对应，方便数据封装与传输。

也叫：
- 实体类
- JavaBean
- POJO类
- Domain对象
### 1.2创建实体类的原因

`因为mysql的数据转到java中默认是零散的，不宜管理，所以要通过实体类，对mysql表进行封装,表数据就更容易管理，后期也更容易扩展`

# 2.ORM

	ORM是JDBC/MyBatis/Hibernate非常核心的概念
### 2.1什么是ORM

`Object Relational Mapping（对象关系映射） 简单的说就是将数据库表映射成java对象`

举例：
数据库中student的信息是如下格式
```mysql
create table student(
	student_id int primary key,
	stu_name varchar(10) not null,
	stu_age int not null,
	gender char(1) not null
) comment '学生表';

```

| 数据库中信息的显示 | student_id | stu_name | stu_age | gender |
| --------- | ---------- | -------- | ------- | ------ |
|           | 1          | 张三       | 23      | 男      |
java中数据显示如下格式

# 3.主键回显

	主键回显是JDBC/MyBatis?ORM中非常常见的知识点

###  3.1.干嘛用的呢?

`插入数据后，自动获取数据库生成的主键ID`

### 3.2. 为什么需要主键回显

`数据库中，id是自增主键，那么此时java是不知道当前数据id号是多少，那么此时就需要利用逐渐重现为java返回id号`

# 4.JDBC批处理

### 4.1 批处理的定义

	批处理就是一次执行多条sql语句

### 4.2为什么要使用批处理

	普通方式（效率太低）->
			1.每次都要连接数据库
			2.每次都执行sql
			3.性能非常低
    批处理方式（效率高）
		    设置参数  
				↓  
			addBatch()  
				↓  
			addBatch()  
				↓  
			addBatch()  
				↓  
			executeBatch()  
				↓  
			一次执行
---

### 4.3完整代码

```java
public class Batch {  
    public static void main(String[] args) throws Exception {  
        getBatch();  
    }  
	  
    public static void getBatch() throws Exception{  
	    // 1.获取连接对象
	    // ?rewriterBatchedStatements = true开启批处理
        Connection connection = DriverManager.getConnection("jdbc:mysql://localhost:3306/mydb_1?rewriterBatchedStatements = true", "root", "250712");  
		//2.预编译SQL  
        String sql = "insert into t_emp(emp_name,emp_salary,emp_age) values(?,?,?)";  
        PreparedStatement preparedStatement = connection.prepareStatement(sql);  
  
        long start = System.currentTimeMillis();  
        for (int i = 1; i <= 10000; i++) {  
		    //3.赋值
            preparedStatement.setString(1,"marry"+i);  
            preparedStatement.setDouble(2,100.00+i);  
            preparedStatement.setInt(3,20+i);  
			// 把SQL先存起来，不执行
            preparedStatement.addBatch();  
        }  
		  // 执行sql语句
        preparedStatement.executeBatch();  
  
        long end = System.currentTimeMillis();  
	  
        System.out.println("执行时间为："+(end-start));
        prepareStatement.clearBatch();
        preparedStatement.close();  
        connection.close();  
  
    }  
}
```

#  5.JDBC连接池

### 5.1 什么是JDBC连接池
	jdbc连接池就是提前创建好的一堆数据库连接，谁用谁拿，用完了还回来
例： 今天我要订酒店：
	没有连接池 -->每次来客人都要临时建房子
	有连接池 --> 提前建好房子，直接入住

### 5.2为什么要有连接池

	没有连接池：
		1.建立数据库连接非常消耗资源
		2.频繁创建/销毁会导致系统变慢
	使用连接池的好处：
		1.提高性能，不用频繁创建连接
		2.减少数据库压力，不用频繁创建连接
		3.统一管理连接
### 5.3常用连接池
	1.Druid
	2.HiKariCP
