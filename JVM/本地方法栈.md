
> **本地方法栈负责执行 Native 方法（由C/C++等其他语言实现的方法），为JVM调用本地代码提供运行空间。**

---

# 1. 为什么需要本地方法栈？

Java并不是所有功能都是自己实现的。

例如：

Java代码：

```
public native void start();
```

这里的：

```
native
```

表示：

> 这个方法不是Java写的，而是调用操作系统底层代码。

例如：

- 文件操作
- 网络通信
- 操作系统线程
- 内存管理

这些底层功能通常由：

- C
- C++

实现。

---

# 2. Java方法 vs Native方法

## Java方法

例如：

```
public void hello(){

    System.out.println("hello");

}
```

执行：

```
Java代码

↓

Java虚拟机栈
```

---

## Native方法

例如：

```
public native void sleep(long millis);
```

执行：

```
Java代码

↓

本地方法栈

↓

C/C++代码

↓

操作系统
```

---

# 3. 本地方法栈和虚拟机栈的区别

这是面试常问。

||虚拟机栈|本地方法栈|
|---|---|---|
|执行|Java方法|Native方法|
|语言|Java|C/C++等|
|保存|Java栈帧|Native栈帧|
|线程|线程私有|线程私有|
|作用|运行Java代码|调用操作系统能力|

---

举个例子：

## Java代码

```
public class Test {

    public static void main(String[] args){

        Thread.sleep(1000);

    }
}
```

执行过程：

### 第一步

main进入：

```
虚拟机栈

main()
```

---

### 第二步

调用：

```
Thread.sleep()
```

这个方法底层：

```
public static native void sleep(long millis);
```

---

### 第三步

进入：

```
本地方法栈

sleep()
```

---

### 第四步

调用：

```
操作系统线程调度
```

---

# 4. 本地方法栈里面存什么？

和虚拟机栈类似：

保存：

> Native方法执行过程中的栈帧。

结构：

```
本地方法栈

Native栈帧

├── 局部变量
├── 操作数
├── 返回地址
└── 其他本地信息
```

# 5. 常见Native方法

## ① Thread.sleep()

源码：

```
public static native void sleep(long millis);
```

底层：

操作系统暂停当前线程。

---

## ② Object.clone()

源码：

```
protected native Object clone();
```

底层复制对象。

---

## ③ System.currentTimeMillis()

源码：

```
public static native long currentTimeMillis();
```

底层获取系统时间。

---

## ④ System.arraycopy()

源码：

```
public static native void arraycopy(...)
```

底层进行高速内存复制。

# 6. JVM运行流程总结

一个Java程序：

```
public class Demo{

    public static void main(String[] args){

        System.out.println("hello");

    }

}
```

运行：

```
.class文件

↓

类加载器

↓

运行时数据区


             JVM

  程序计数器
       |
       |
  虚拟机栈
       |
       |
  堆
       |
       |
  方法区


如果调用native：

       ↓

  本地方法栈

       ↓

  操作系统
```

# 7. 本地方法栈会出现什么错误？

## StackOverflowError

例如：

Native调用层级过深。

---

## OutOfMemoryError

例如：

创建大量线程：

```
线程1
 |
本地方法栈

线程2
 |
本地方法栈

线程3
 |
本地方法栈

...

内存耗尽
```

# 8. 面试回答版

面试官：

> JVM本地方法栈是什么？

回答：

> 本地方法栈和虚拟机栈类似，都是线程私有的内存区域。区别是虚拟机栈用于执行Java方法，而本地方法栈用于执行Native方法。当Java调用操作系统底层功能时，会通过本地方法栈完成，比如Thread.sleep、System.currentTimeMillis等方法。
