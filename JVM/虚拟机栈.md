

> **虚拟机栈负责保存Java方法执行过程中的栈帧，每调用一个方法，就创建一个栈帧，方法结束，栈帧销毁。**

---

# 1. 栈在哪里？

JVM内存结构：

```
JVM运行时数据区


线程共享
-------------------
堆（Heap）
方法区（Method Area）


线程私有
-------------------
程序计数器
虚拟机栈 ⭐
本地方法栈
```

特点：

- 每个线程都有自己的虚拟机栈
- 生命周期和线程一致

例如：

```
线程A

虚拟机栈
   |
   |--main()
   |--test()


线程B

虚拟机栈
   |
   |--run()
```

两个线程互不影响。

---

# 2. 栈里面存什么？

栈里面存的是：

## 栈帧（Stack Frame）

每调用一个Java方法：

就创建一个栈帧。

例如：

```
public class Demo {

    public static void main(String[] args){

        method1();

    }


    public static void method1(){

        int a = 10;

    }
}
```

执行过程：

---

进入main：

```
虚拟机栈

| main()栈帧 |
```

---

调用method1：

```
虚拟机栈

| method1()栈帧 |
| main()栈帧    |
```

---

method1执行结束：

```
虚拟机栈

| main()栈帧 |
```

---

main结束：

```
空
```

---

# 3. 栈帧结构（重点）

一个栈帧主要包含4部分：

```
栈帧

├── 局部变量表 ⭐
├── 操作数栈 ⭐
├── 动态链接
└── 方法出口
```

---

# 一、局部变量表（Local Variable Table）

保存：

- 方法参数
- 局部变量

例如：

```
public void test(){

    int a = 10;

    String name="张三";

}
```

栈帧：

```
局部变量表

slot0  this

slot1  a=10

slot2  name
```

---

注意：

基本数据类型：

直接保存值：

```
a=10
```

---

引用类型：

保存地址：

```
name
 |
 ↓
堆中的String对象
```

例如：

```
User user=new User();
```

内存：

```
栈：

user
 |
 |
 ↓

堆：

User对象
{
 id=1
}
```

---

# 二、操作数栈（Operand Stack）

JVM执行字节码时使用。

例如：

Java：

```
int c = a+b;
```

字节码执行：

```
加载a

↓

加载b

↓

执行iadd

↓

保存c
```

操作数栈：

第一步：

```
10
```

第二步：

```
10
20
```

执行加法：

```
30
```

---

简单理解：

> 操作数栈就是JVM计算时的临时工作空间。

---

# 三、动态链接

作用：

将符号引用转换成实际方法地址。

例如：

```
user.say();
```

编译时：

```
say方法
```

只是一个名字。

运行时：

找到：

```
User.class

↓

say()

↓

真实地址
```

---

# 四、方法出口

保存方法执行完成后：

返回哪里。

例如：

```
main(){

    test();

    System.out.println("结束");

}
```

执行：

```
main

↓

test()

↓

返回main

↓

执行打印
```

方法出口记录：

```
回到main哪一行继续执行
```

# 4. 栈和堆的区别（面试必问）

||栈|堆|
|---|---|---|
|存储|栈帧|对象|
|线程|私有|共享|
|速度|快|慢|
|生命周期|方法结束销毁|GC管理|
|空间|较小|较大|

例如：

```
public void test(){

    User u=new User();

    int age=18;

}
```

内存：

```
栈：

test栈帧

u  ---------
age=18     |
           |
           ↓

堆：

User对象
{
}
```

# 5. 栈溢出 StackOverflowError


- 栈帧过多导致占内存溢出
- 栈帧过大导致栈内存溢出



最经典：

递归无限调用：

```
public void test(){

    test();

}
```

执行：

```
test()
 |
test()
 |
test()
 |
test()
...
```

不断创建栈帧：

```
栈

|test|
|test|
|test|
|test|
|test|
```

最终：

```
StackOverflowError
```

# 6. 栈会发生OOM吗？

一般不会。

虚拟机栈可能：

## StackOverflowError

栈深度超过限制：

```
递归太深
```

---

## OutOfMemoryError

线程创建太多：

例如：

```
while(true){

new Thread().start();

}
```

每个线程需要一个栈。

线程太多：

```
内存不足
```

# 7. 面试回答版本

面试问：

> JVM虚拟机栈是什么？

回答：

> Java虚拟机栈是线程私有的内存区域，用于描述Java方法执行过程。每调用一个方法都会创建一个栈帧，栈帧中包含局部变量表、操作数栈、动态链接和方法出口等信息。方法执行完成后对应栈帧会被销毁。
