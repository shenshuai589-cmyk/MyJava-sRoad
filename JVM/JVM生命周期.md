

JVM生命周期指的是：

> **从JVM启动，到执行Java程序，再到JVM关闭的整个过程。**

简单理解：

```
JVM启动
   ↓
加载类
   ↓
执行程序
   ↓
运行时管理内存
   ↓
JVM关闭
```

---

# 一、JVM启动（Startup）

当我们执行：

```
java Test
```

发生：

```
Java命令
   ↓
启动JVM进程
   ↓
创建运行时环境
```

JVM开始初始化：

主要创建：

### 1. 类加载器

负责加载 `.class` 文件。

例如：

```
Test.class
```

加载：

```
ClassLoader
      ↓
方法区
```

---

### 2. 初始化运行时数据区

创建：

```
线程私有：
----------------
程序计数器
虚拟机栈
本地方法栈


线程共享：
----------------
堆
方法区
```

---

### 3. 创建主线程

JVM启动后：

第一个线程：

```
main线程
```

执行：

```
public static void main(String[] args)
```

---

# 二、类加载阶段（Loading）

JVM运行Java程序前，需要先加载类。

例如：

```
public class User {

}
```

编译：

```
User.java

↓

User.class
```

运行：

```
User.class

↓

类加载器

↓

方法区
```

---

类加载过程：

## 1. 加载

找到class文件：

```
User.class
```

读取内容。

---

## 2. 验证

检查：

- class文件格式
- 字节码安全

---

## 3. 准备

给静态变量分配空间。

例如：

```
static int count = 10;
```

准备阶段：

```
count = 0
```

---

## 4. 解析

符号引用转换为直接引用。

---

## 5. 初始化

执行：

```
static {

}
```

例如：

```
static int count=10;
```

此时：

```
count=10
```

---

# 三、执行阶段（Execution）⭐⭐⭐

这是JVM生命周期最长的阶段。

流程：

```
Java代码

↓

.class字节码

↓

JVM执行引擎

↓

CPU执行
```

---

执行引擎包含：

## 1. 解释器

逐条执行字节码。

例如：

```
指令1
执行

指令2
执行
```

优点：

启动快。

缺点：

执行慢。

---

## 2. JIT即时编译器

发现热点代码：

例如：

```
for(int i=0;i<100000;i++){

}
```

执行很多次。

JIT：

```
字节码

↓

机器码

↓

直接执行
```

提高性能。

---

# 四、内存管理阶段

JVM运行过程中：

负责：

## 1. 创建对象

例如：

```
User user=new User();
```

过程：

```
栈：

user引用


↓

堆：

User对象
```

---

## 2. 垃圾回收 GC

对象不用后：

例如：

```
user=null;
```

对象：

```
没有引用

↓

垃圾对象

↓

GC回收
```

---

GC负责：

- 新生代回收
- 老年代回收
- 内存整理

---

# 五、JVM关闭阶段（Shutdown）

JVM关闭情况：

## 1. 正常结束

例如：

main方法执行完：

```
public static void main(){

}
```

结束：

```
main线程结束

↓

JVM退出
```

---

## 2. 主动关闭

调用：

```
System.exit(0);
```

---

## 3. 强制关闭

例如：

操作系统：

```
kill JVM进程
```

---

# 六、JVM关闭时做什么？

JVM退出前：

会执行：

## Shutdown Hook（关闭钩子）

例如：

```
Runtime.getRuntime()
.addShutdownHook(
    new Thread(){

    }
);
```

可以做：

- 保存数据
- 释放资源
- 关闭连接

# 面试回答版本 ⭐

面试官：

> 简述一下JVM生命周期。

回答：

> JVM生命周期主要包括启动、运行和关闭三个阶段。启动阶段JVM创建运行环境并初始化运行时数据区域；运行阶段通过类加载器加载Class文件，执行引擎执行字节码，同时负责内存管理和垃圾回收；关闭阶段会执行关闭钩子并释放资源，最终结束JVM进程。
