# 一、排序suanfa

## 1. 冒泡排序 Bubble Sort

思想：相邻元素比较大小，大的往后移

例如：

```
5 3 8 1

第一轮：

3 5 1 8

第二轮：

3 1 5 8

第三轮：

1 3 5 8
```


若数组的长度为n,则需要遍历n-1轮

代码：

```java
public static void bubbleSort(int[] arr){

    for(int i=0;i<arr.length-1;i++){

        for(int j=0;j<arr.length-i-1;j++){

            if(arr[j]>arr[j+1]){

                int temp=arr[j];

                arr[j]=arr[j+1];

                arr[j+1]=temp;

            }
        }
    }
}
```

## 2. 选择排序（Selection Sort）

## 思想

每轮找到最小值，放到前面。

例如：

```
5 3 8 1

找到1

1 3 8 5
```


代码：

```
public static void selectSort(int[] arr){

    for(int i=0;i<arr.length-1;i++){

        int min=i;


        for(int j=i+1;j<arr.length;j++){

            if(arr[j]<arr[min]){

                min=j;

            }
        }


        int temp=arr[i];

        arr[i]=arr[min];

        arr[min]=temp;

    }
}
```

## 3.插入排序（Insertion Sort）

## 思想

像整理扑克牌：

已经排好的区域插入新元素。


代码：

```
public static void insertSort(int[] arr){

    for(int i=1;i<arr.length;i++){

        int temp=arr[i];

        int j=i-1;


        while(j>=0 && arr[j]>temp){

            arr[j+1]=arr[j];

            j--;

        }


        arr[j+1]=temp;

    }

}
```
