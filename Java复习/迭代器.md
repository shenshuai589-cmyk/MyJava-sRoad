
迭代器（Iterator）是 Java 集合中用于**遍历集合元素的一种方式**。

简单理解：

> Iterator 提供了一种统一访问集合元素的方法，不需要关心集合底层的数据结构。

例如：

- ArrayList 底层是数组
- LinkedList 底层是链表
- HashSet 底层是哈希表

但是都可以使用 Iterator 遍历。

---

# 一、为什么需要 Iterator？

假设没有迭代器：

ArrayList：

```
for(int i=0;i<list.size();i++){
    System.out.println(list.get(i));
}
```

可以。

但是 HashSet：

```
set.get(i);
```

不存在。

因为 Set 没有索引。

所以 Java 提供：

```
Iterator
```

统一遍历。

---

# 二、Iterator 接口

所在包：

```
java.util.Iterator
```

源码：

```
public interface Iterator<E>{

    boolean hasNext();

    E next();

    default void remove();

}
```

主要方法：

|方法|作用|
|---|---|
|hasNext()|判断是否还有元素|
|next()|获取下一个元素|
|remove()|删除当前元素|

---

# 三、Iterator 基本使用

例如：

```
List<String> list = new ArrayList<>();

list.add("Java");
list.add("MySQL");
list.add("Redis");


Iterator<String> iterator = list.iterator();


while(iterator.hasNext()){

    String s = iterator.next();

    System.out.println(s);

}
```

输出：

```
Java
MySQL
Redis
```

---

# 四、Iterator执行过程（重点）

代码：

```
Iterator<String> iterator=list.iterator();
```

得到一个迭代器对象：

```
Iterator
    |
    |
集合内部遍历工具
```

执行：

```
iterator.hasNext()
```

判断：

```
当前位置 < 集合长度?
```

如果有：

执行：

```
iterator.next()
```

流程：

```
创建Iterator
       |
       ↓
hasNext()
       |
       ↓
next()
       |
       ↓
返回元素
       |
       ↓
继续循环
```

# 五、Iterator 删除元素（重点）

错误方式：

```
List<String> list =
new ArrayList<>();

list.add("Java");
list.add("MySQL");


for(String s:list){

    if(s.equals("Java")){
        list.remove(s);
    }

}
```

可能报：

```
ConcurrentModificationException
```

原因：

> 遍历过程中修改集合结构。

---

正确方式：

使用 Iterator 的 remove()

```
Iterator<String> iterator =
list.iterator();


while(iterator.hasNext()){

    String s=iterator.next();


    if(s.equals("Java")){

        iterator.remove();

    }

}
```

---

# 六、为什么 iterator.remove() 不会报错？

因为：

普通删除：

```
list.remove()
```

修改：

```
集合结构
```

但是 Iterator 不知道。

---

Iterator删除：

```
iterator.remove()
```

会同步修改：

```
集合
+
迭代器状态
```

所以安全。

---

# 七、foreach 和 Iterator 的关系（面试重点）

增强 for：

```
for(String s:list){

    System.out.println(s);

}
```

底层实际上：

```
Iterator<String> it =
list.iterator();


while(it.hasNext()){

    String s=it.next();

}
```

也就是说：

> foreach 本质上就是 Iterator。

# 九、Iterator底层原理

以 ArrayList 为例：

ArrayList：

```
Object[] elementData;
```

Iterator：

内部保存：

```
private int cursor;
```

cursor：

表示当前遍历位置。

例如：

数组：

```
[Java][MySQL][Redis]

  ^
 cursor=0
```

调用：

```
next()
```

移动：

```
[Java][MySQL][Redis]

        ^
     cursor=1
```

# 十、fail-fast机制（面试重点）

Iterator 有一个机制：

> 快速失败（fail-fast）

例如：

```
List<String> list =
new ArrayList<>();


Iterator<String> it =
list.iterator();


list.add("Java");


it.next();
```

可能：

```
ConcurrentModificationException
```

原因：

Iterator 保存：

```
expectedModCount
```

集合保存：

```
modCount
```

修改集合：

```
modCount++
```

遍历时：

比较：

```
expectedModCount
        |
        |
     是否相等
```

不一致：

抛异常。

||for循环|Iterator|
|---|---|---|

# 十二、Java后端面试回答模板

面试问：

## Iterator是什么？

回答：

> Iterator 是 Java 集合提供的一种统一遍历机制，通过 hasNext() 判断是否存在元素，通过 next() 获取元素，可以屏蔽不同集合底层结构的差异。

---

## foreach底层是什么？

回答：

> 增强 for 循环底层依赖 Iterator 实现，对于实现 Iterable 接口的集合，编译器会转换成 Iterator 遍历。

---

## 为什么不能遍历时删除集合？

回答：

> 因为直接修改集合会改变 modCount，而 Iterator 内部维护 expectedModCount，两者不一致会触发 ConcurrentModificationException。应该使用 Iterator.remove()。
