
> **泛型就是把类型作为参数传递，让类、接口、方法可以在使用时确定具体类型。**

例如：

没有泛型：

```
ArrayList list = new ArrayList();

list.add("张三");
list.add(18);

String name = (String) list.get(0);
```

问题：

- 什么类型都可以放
- 取出时需要强转
- 容易出现类型转换异常

使用泛型：

```
ArrayList<String> list = new ArrayList<>();

list.add("张三");

String name = list.get(0);
```

优点：

- 类型安全
- 不需要强转
- 提高代码复用性

---

# 一、为什么需要泛型？

## 1. 没有泛型的问题

例如：

```
ArrayList list = new ArrayList();

list.add("Java");

list.add(100);


String s = (String) list.get(1);
```

运行：

```
ClassCastException
```

原因：

集合不知道存储的是什么类型。

---

## 2. 泛型解决

```
ArrayList<String> list = new ArrayList<>();

list.add("Java");

// list.add(100); 编译错误
```

编译阶段直接检查：

保证集合里面只能存 String。

---

# 二、泛型的基本使用

## 1. 泛型类

格式：

```
class 类名<T>{

}
```

T：

Type 类型占位符。

例如：

```
public class Box<T>{

    private T value;


    public void setValue(T value){

        this.value = value;

    }


    public T getValue(){

        return value;

    }

}
```

使用：

```
Box<String> box = new Box<>();

box.setValue("Java");

String s = box.getValue();
```

此时：

```
T = String
```

---

# 三、泛型接口

格式：

```
interface 接口名<T>{

}
```

例如：

```
interface Data<T>{

    T getData();

}
```

实现：

```
class StringData implements Data<String>{

    public String getData(){

        return "hello";

    }

}
```

此时：

```
T = String
```

---

# 四、泛型方法

泛型方法：

> 方法自己的泛型参数。

格式：

```
public <T> T 方法名(T 参数){

}
```

例如：

```
public class Test{


    public static <T> void print(T value){

        System.out.println(value);

    }

}
```

调用：

```
Test.print("Java");

Test.print(100);

Test.print(true);
```

编译器自动推断：

第一次：

```
T=String
```

第二次：

```
T=Integer
```

---

# 五、泛型通配符 ?

## 1. 为什么需要 ?

例如：

```
ArrayList<String>
```

和：

```
ArrayList<Object>
```

没有继承关系。

虽然：

```
String 是 Object 子类
```

但是：

```
ArrayList<String>
不是
ArrayList<Object>
```

所以：

需要通配符。

---

# 六、无界通配符 ?

表示：

> 任意类型

例如：

```
List<?> list;
```

可以接收：

```
List<String>

List<Integer>

List<Student>
```

但是：

不能添加元素：

```
list.add("hello"); //错误
```

因为不知道具体类型。

---

# 七、上限通配符 extends

格式：

```
<? extends 父类>
```

表示：

> 可以传入父类以及父类的子类。

例如：

```
List<? extends Number>
```

可以：

```
List<Integer>

List<Double>
```

不能：

```
List<String>
```

特点：

只能读取，不能添加。

例如：

```
List<? extends Number> list;


Number n = list.get(0);
```

可以。

但是：

```
list.add(10);
```

错误。

原因：

不知道具体类型。

可能：

```
Integer
Double
```

---

# 八、下限通配符 super

格式：

```
<? super 子类>
```

表示：

> 可以接收该类以及它的父类。

例如：

```
List<? super Integer>
```

可以：

```
List<Integer>

List<Number>

List<Object>
```

特点：

可以添加子类。

例如：

```
list.add(10);
```

可以。

# 九、PECS原则（面试重点）

Java泛型：

## Producer Extends

生产者：

只读：

使用：

```
extends
```

例如：

```
List<? extends Number>
```

---

## Consumer Super

消费者：

只写：

使用：

```
super
```

例如：

```
List<? super Integer>
```

口诀：

> **读用extends，写用super**

# 十、泛型擦除（重点面试）

Java泛型：

> 编译期间存在，运行期间不存在。

例如：

代码：

```
ArrayList<String>
```

编译后：

```
ArrayList
```

类型信息被擦除。

叫：

```
类型擦除(Type Erasure)
```

---

# 十一、为什么 Java 使用泛型擦除？

原因：

Java为了兼容旧版本。

Java5之前：

没有泛型。

如果运行时保留泛型：

老代码无法兼容。

所以：

编译阶段检查：

↓

生成普通字节码

---

# 十二、泛型不能使用基本数据类型

错误：

```
List<int>
```

正确：

```
List<Integer>
```

原因：

泛型只能使用引用类型。

基本类型对应包装类：

|基本类型|包装类|
|---|---|
|int|Integer|
|double|Double|
|boolean|Boolean|

---

例如：

底层：

实际上：

```
Object[] elementData;
```

取出：

```

(String)object
```

# 十四、泛型面试常问

## 1. 什么是泛型？

回答：

> 泛型是Java提供的一种参数化类型机制，可以把类型作为参数传递，提高代码复用性和类型安全。

---

## 2. 泛型什么时候确定？

回答：

> 泛型类型在编译期间确定，运行期间会进行类型擦除。

---

## 3. <? extends T 和 <? super T区别？

回答：

||extends|super|
|---|---|---|
|方向|向上限制|向下限制|
|用途|读取|写入|
|口诀|生产者|消费者|

---

## 4. 为什么不能new泛型数组？

错误：

```
T[] arr = new T[10];
```

原因：

运行时不知道T具体类型。
