
# 一、Java线程6种状态

Java中线程状态定义在：

```
java.lang.Thread.State
```

源码：

```
public enum State {

    NEW,

    RUNNABLE,

    BLOCKED,

    WAITING,

    TIMED_WAITING,

    TERMINATED
}
```

一共6种：

|状态|含义|
|---|---|
|NEW|新建状态|
|RUNNABLE|运行状态|
|BLOCKED|阻塞状态|
|WAITING|等待状态|
|TIMED_WAITING|超时等待状态|
|TERMINATED|终止状态|

---

# 三、NEW（新建状态）

## 1. 什么情况下进入NEW？

创建线程对象：

```
Thread t = new Thread();
```

此时：

线程对象存在，但是没有真正运行。

状态：

```
NEW
```

例如：

```
public class Test {

    public static void main(String[] args){

        Thread t = new Thread();

        System.out.println(t.getState());

    }

}
```

输出：

```
NEW
```

---

## 2. NEW特点

此时：

- 线程还没有启动
- JVM还没有创建操作系统线程
- 不会执行run()

---

# 四、RUNNABLE（运行状态）

## 1. 如何进入？

调用：

```
t.start();
```

例如：

```
Thread t=new Thread(){

    public void run(){

        System.out.println("执行");

    }

};


t.start();
```

状态：

```
NEW

↓

RUNNABLE
```

---

## 2. RUNNABLE包含什么？

Java中的：

```
RUNNABLE
```

实际上包含：

两个状态：

```
READY（就绪）

RUNNING（运行）
```

但是Java没有细分。

---

例如：

线程已经启动：

```
RUNNABLE
```

但是：

CPU可能正在执行其他线程。

---

# 五、BLOCKED（阻塞状态）

## 1. 什么情况进入BLOCKED？

等待获取锁。

例如：

线程A：

```
synchronized(lock){

    while(true){

    }

}
```

线程A获得锁。

线程B：

```
synchronized(lock){

}
```

此时：

线程B：

```
BLOCKED
```

---

## 2. 状态变化

```
RUNNABLE

     |
     |
等待synchronized锁

     ↓

BLOCKED

     |
     |
获得锁

     ↓

RUNNABLE
```

---

# 六、WAITING（无限等待）

## 1. 什么情况进入WAITING？

没有时间限制的等待。

主要方法：

### wait()

```
object.wait();
```

### join()

```
thread.join();
```

### LockSupport.park()

```
LockSupport.park();
```

---

例如：

线程：

```
synchronized(lock){

    lock.wait();

}
```

状态：

```
WAITING
```

---

## 2. WAITING如何恢复？

必须被唤醒：

例如：

```
notify()
```

或者：

```
notifyAll()
```

流程：

```
WAITING

   |
 notify()

   ↓

BLOCKED

   |
 获取锁

   ↓

RUNNABLE
```

注意：

notify之后：

不会直接执行。

需要重新竞争锁。

---

# 七、TIMED_WAITING（超时等待）

## 1. 什么情况进入？

带时间的等待。

例如：

---

## sleep()

```
Thread.sleep(1000);
```

状态：

```
TIMED_WAITING
```

---

## wait(time)

```
lock.wait(1000);
```

---

## join(time)

```
thread.join(1000);
```

---

状态：

```
RUNNABLE

↓

TIMED_WAITING

↓

时间结束

↓

RUNNABLE
```

---

# 八、TERMINATED（终止状态）

## 什么时候进入？

线程执行完成：

```
run()
```

方法结束。

例如：

```
public void run(){

    System.out.println("hello");

}
```

执行结束：

```
TERMINATED
```

---

## 注意

线程死亡后：

不能重新启动。

错误：

```
thread.start();

thread.start();
```

第二次：

报：

```
IllegalThreadStateException
```

# 九、几个常见方法对应状态（面试必背）

|方法|进入状态|
|---|---|
|new Thread()|NEW|
|start()|RUNNABLE|
|sleep()|TIMED_WAITING|
|wait()|WAITING|
|wait(time)|TIMED_WAITING|
|join()|WAITING|
|join(time)|TIMED_WAITING|
|等待synchronized锁|BLOCKED|
|run()执行结束|TERMINATED|

---

# 十、BLOCKED、WAITING、TIMED_WAITING区别

## BLOCKED

原因：

> 等锁

例如：

```
synchronized(lock)
```

特点：

线程想执行，但是锁被别人占用。

---

## WAITING

原因：

> 主动等待别人通知

例如：

```
wait()
```

特点：

需要：

```
notify()
```

---

## TIMED_WAITING

原因：

> 等待一段时间

例如：

```
sleep(1000)
```

时间到了自动恢复。

---

# 十一、面试回答模板

面试官：

> Java线程有哪些状态？

回答：

> Java线程有6种状态，分别是NEW、RUNNABLE、BLOCKED、WAITING、TIMED_WAITING和TERMINATED。线程创建后处于NEW状态，调用start()进入RUNNABLE状态。线程执行过程中，如果等待锁会进入BLOCKED状态，如果调用wait、join等方法会进入WAITING状态，如果调用sleep或者带时间的wait、join会进入TIMED_WAITING状态，线程执行完成后进入TERMINATED状态。
