

# 1.线程基础

## 1.1 进程

> 进程是操作系统资源分配的基本单位。 （一个正在运行的程序，就是一个进程）


## 1.2 线程

> 线程是CPU调度和执行的基本单位

一个进程里可以有多个线程：

```
一个进程
	|
	|-- 线程1
	|-- 线程2
	|-- 线程3

```

## 1.3 进程和线程的关系

- 一个进程至少包含一个线程
- 一个进程可以包含多个线程
- 线程依赖于进程存在


## 1.4 进程和线程区别

* 1、资源用于不同
   * 进程：拥有独立的资源（进程与进程之间互相隔离）
   * 线程：共享进程资源

* 2.、创建成本不同
   * 进程：创建成本高
   * 线程：创建成本低

## 2. 创建线程方式

必须掌握：

### 方式1：继承Thread

```java
class MyThread extends Thread{

    public void run(){

        System.out.println("执行线程");

    }

}


public class Test{

    public static void main(String[] args){

        MyThread t = new MyThread();

        t.start();

    }
}
```

重点：

面试：

> start()和run()区别？

答案：

```
run()
普通方法调用

start()
创建新线程
由JVM调用run()
```

### 方式3：Callable

学习：

- Callable
- Future
- FutureTask

```java
public class MyCallable implements Callable<Integer> {  
    @Override  
    public Integer call() throws Exception {  
        int[] arr = {1, 2, 3, 4, 5};  
        int sum = 0;  
        for (int i : arr) {  
            sum += i;  
        }  
        return sum;  
    }
}

public static void main(String[] args) throws ExecutionException, InterruptedException {  
    MyCallable myCallable = new MyCallable();  
    FutureTask<Integer> futureTask = new FutureTask<>(myCallable);  
    new Thread(futureTask).start();  
    Integer result = futureTask.get();  
    System.out.println(result);  
}
```

知道：

Runnable：

```
无返回值
```

Callable：

```
有返回值
```
