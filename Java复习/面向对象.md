# Java面向对象三大特性：封装、继承、多态

## 一、封装（Encapsulation）

### 1. 什么是封装

封装是指将对象的属性和行为封装到一个类中，并隐藏内部实现细节，只通过公共方法访问。

核心思想：

-   隐藏对象内部数据
-   控制访问权限
-   提高安全性
-   降低代码耦合

------------------------------------------------------------------------

### 2. 如何实现封装

主要方式：

1.  属性私有化（private）

``` java
private String name;
private int age;
```

2.  提供公共访问方法

``` java
public String getName(){
    return name;
}

public void setName(String name){
    this.name = name;
}
```

------------------------------------------------------------------------

### 3. 封装示例

``` java
class Student {

    private int age;

    public void setAge(int age){

        if(age >= 0 && age <= 150){
            this.age = age;
        }

    }

    public int getAge(){
        return age;
    }

}
```

------------------------------------------------------------------------

### 4. 封装优点

-   提高数据安全性
-   隐藏实现细节
-   提高代码维护性
-   降低类之间的耦合

------------------------------------------------------------------------

# 二、继承（Inheritance）

## 1. 什么是继承

继承表示一个类拥有另一个类的属性和方法。

关键字：

``` java
extends
```

语法：

``` java
class 子类 extends 父类 {

}
```

------------------------------------------------------------------------

## 2. 继承示例

父类：

``` java
class Animal {

    String name;

    public void eat(){
        System.out.println("吃东西");
    }

}
```

子类：

``` java
class Dog extends Animal {

    public void bark(){
        System.out.println("汪汪叫");
    }

}
```

Dog对象可以使用：

-   Animal中的name
-   Animal中的eat()
-   Dog自己的bark()

------------------------------------------------------------------------

## 3. 继承作用

### 代码复用

公共代码放在父类：

``` text
        Animal

       /      \

     Dog      Cat
```

### 提高扩展性

子类可以增加自己的功能。

------------------------------------------------------------------------

## 4. Java继承特点

### 单继承

一个类只能有一个直接父类。

正确：

``` java
class Dog extends Animal {

}
```

错误：

``` java
class Dog extends Animal,Pet {

}
```

------------------------------------------------------------------------

### 多层继承

Java支持：

``` text
Animal

   |

 Dog

   |

Husky
```

------------------------------------------------------------------------

## 5. super关键字

super表示父类对象。

### 访问父类属性

``` java
super.name;
```

### 调用父类方法

``` java
super.eat();
```

### 调用父类构造方法

``` java
super();
```

创建子类对象时：

``` text
父类构造方法

↓

子类构造方法
```

------------------------------------------------------------------------

## 6. 方法重写 Override

子类重新定义父类方法。

``` java
@Override
public void eat(){

    System.out.println("狗吃骨头");

}
```

特点：

-   方法名相同
-   参数列表相同
-   返回值兼容
---

## 7.子类继承父类的哪些属性和方法

子类可以继承父类的非私有成员，包括 `public`、`protected` 和同包下的默认权限成员。

但是：

- `private` 成员不能被子类直接访问
- 构造方法不能被继承
- 静态成员可以被继承，但属于父类
### 7.2. Java访问权限修饰符

Java中有四种访问权限：

|修饰符|同类|同包|子类|其他包|
|---|---|---|---|---|
|public|√|√|√|√|
|protected|√|√|√|×|
|默认(default)|√|√|×|×|
|private|√|×|×|×|
### 7.3 private成员到底有没有被继承？

这是面试重点。

严格来说：

> private成员会存在于子类对象中，但是子类无法直接访问。

### 7.4如何访问父类private成员？

通过父类提供的方法。
例如：

```
class Animal {


    private String name;


    public void setName(String name){

        this.name = name;

    }


    public String getName(){

        return name;

    }

}
```

子类：

```
class Dog extends Animal {

}
```

调用：

```
Dog dog = new Dog();

dog.setName("旺财");

System.out.println(dog.getName());
```

## 子类能继承父类哪些成员？

标准答案：

> Java中子类可以继承父类的非私有成员，包括public、protected以及同包下的默认成员。private成员虽然存在于子类对象中，但是由于访问权限限制，子类不能直接访问。构造方法不能继承，静态成员可以继承但属于父类。

# 三、多态（Polymorphism）

## 1. 什么是多态

多态表示同一个对象，在不同情况下表现出不同形态。

Java实现：

``` java
父类引用 = 子类对象;
```

例如：

``` java
Animal animal = new Dog();
```

------------------------------------------------------------------------

## 2. 多态示例

父类：

``` java
class Animal {

    public void eat(){
        System.out.println("动物吃东西");
    }

}
```

子类：

``` java
class Dog extends Animal {

    @Override
    public void eat(){
        System.out.println("狗吃骨头");
    }

}
```

调用：

``` java
Animal animal = new Dog();

animal.eat();
```

输出：

``` text
狗吃骨头
```

------------------------------------------------------------------------

## 3. 多态调用规则

### 编译看左边

决定能调用哪些方法。

### 运行看右边

决定执行哪个方法。

也叫：

动态绑定。

------------------------------------------------------------------------

## 4. 多态三个必要条件

1.  存在继承关系

``` java
Dog extends Animal
```

2.  子类重写父类方法

``` java
@Override
```

3.  父类引用指向子类对象

``` java
Animal a = new Dog();
```

------------------------------------------------------------------------

## 5. 多态优势

### 提高扩展性

例如：

``` java
public void eatAnimal(Animal animal){

    animal.eat();

}
```

以后增加Dog、Cat，不需要修改方法。

### 降低耦合

面向父类编程。

## 4. this和super区别

             this         super
  ---------- ------------ ----------
  代表       当前对象     父类对象
  访问       当前类成员   父类成员
  调用构造   this()       super()

------------------------------------------------------------------------

## 5. 重载和重写区别

             重载       重写
  ---------- ---------- ----------
  英文       Overload   Override
  位置       同一个类   父子类
  参数       必须不同   必须相同
  发生时间   编译期     运行期
