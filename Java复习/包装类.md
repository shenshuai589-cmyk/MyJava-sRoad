
## 一、什么是包装类？

Java 中有 **8种基本数据类型**：

```
byte
short
int
long
float
double
char
boolean
```

但是基本数据类型不是对象，不能：

- 调用方法
- 泛型使用
- 集合存储

所以 Java 为每种基本类型提供了一个对应的**包装类**。

---

|---|---|

|char|Character|
|boolean|Boolean|

其中：

重点：

```

char → Character
```

# 三、为什么需要包装类？

## 1. 集合只能存对象（★★★★★）

例如：

```
List<int> list;
```

错误！

Java 泛型不能使用基本类型。

必须：

```
List<Integer> list =
        new ArrayList<>();
```

添加：

```
list.add(10);
```

这里发生：

```
int
 ↓
Integer
```

自动装箱。

---

## 2. 包装类提供工具方法

例如：

Integer：

```
Integer.parseInt("123");
```

字符串转 int。

String：

```
String.valueOf(123);
```

转字符串。

---

# 四、自动装箱和自动拆箱（★★★★★）

Java5 引入。

---

# 1. 自动装箱（Auto Boxing）

基本类型：

↓

包装类

例如：

```
Integer num = 10;
```

实际上：

```
Integer num =
        Integer.valueOf(10);
```

---

过程：

```
int 10

↓

Integer对象
```

---

# 2. 自动拆箱（Unboxing）

包装类：

↓

基本类型

例如：

```
Integer num = 10;

int a = num;
```

实际上：

```
int a =
    num.intValue();
```

---

过程：

```
Integer对象

↓

int
```

---

# 五、Integer 底层原理（★★★★★ 面试重点）

Integer 是面试最高频包装类。

源码：

```
public final class Integer 
extends Number 
implements Comparable<Integer>
```

---

## 1. Integer 缓存机制

看代码：

```
Integer a = 100;
Integer b = 100;


System.out.println(a == b);
```

结果：

```
true
```

为什么？

因为 Integer 默认缓存：

```
-128 ~ 127
```

范围内的对象。

---

执行：

```
Integer a=100;
```

实际上：

```
Integer.valueOf(100);
```

进入缓存：

```
IntegerCache
```

返回已有对象。

所以：

```
a地址
=
b地址
```

---

## 2. 超过缓存范围

例如：

```
Integer a=200;
Integer b=200;


System.out.println(a==b);
```

结果：

```
false
```

原因：

创建两个不同对象。

---

正确比较：

```
a.equals(b);
```

结果：

```
true
```

---

# 六、Integer.valueOf() 底层

源码思想：

```
public static Integer valueOf(int i){

    if(i>=-128 && i<=127)

        return IntegerCache.cache[i+128];

    return new Integer(i);

}
```

逻辑：

```
范围内
 |
缓存对象

范围外
 |
创建新对象
```

# 七、包装类和 == 的坑（★★★★★）

## 1. Integer比较

true

# 九、包装类为什么设计成不可变？（面试）

例如：

```
Integer i=100;
```

不能修改：

```
i.value=200;
```

原因：

---

## 1. 保证线程安全

多个线程共享 Integer：

不会被修改。

---

## 2. 支持缓存

例如：

```
Integer a=100;
Integer b=100;
```

可以复用同一个对象。

---

## 3. 适合作为 HashMap Key

HashMap要求：

对象hashCode稳定。

# 十一、包装类和基本类型区别

||基本类型|包装类|
|---|---|---|
|是否对象|否|是|
|存储位置|栈|堆对象|
|默认值|0|null|
|能否调用方法|否|可以|
|泛型支持|否|支持|
|效率|高|低|
