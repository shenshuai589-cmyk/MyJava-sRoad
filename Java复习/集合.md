# 一、为什么需要集合？

数组：

```
int[] arr = new int[10];
```

缺点：

1. 长度固定

```
new int[10]
```

创建后不能改变。

2. 类型单一
3. 操作不方便

集合：

```
List<Integer> list = new ArrayList<>();
```

优点：

- 动态扩容
- 提供大量 API
- 支持不同数据结构

---

# 二、Java 集合体系结构（重点）

Java 集合主要分两大体系：

```
                 Collection
                     |
        -----------------------------
        |                           |
       List                        Set
        |                           |
 ArrayList                     HashSet
 LinkedList                   LinkedHashSet
 Vector                       TreeSet


                 Map
                  |
        ----------------
        |
     HashMap
     LinkedHashMap
     TreeMap
     ConcurrentHashMap
```

注意：

> Map 不属于 Collection。

# 四、List接口（重点）

特点：

> 有序、可重复、有索引。

例如：

```
List<String> list =
new ArrayList<>();

list.add("A");
list.add("A");
```

结果：

```
[A,A]
```

# 五、ArrayList（重点）

## 1. 底层结构

ArrayList：

> 底层是动态数组。

源码：

```
transient Object[] elementData;
```

结构：

```
数组

[10][20][30][40]
```

---

## 2. 默认容量

Java8：

创建：

```
ArrayList list =
new ArrayList();
```

初始：

```
0
```

第一次添加：

```
add()
```

扩容：

```
10
```

---

## 3. 扩容机制（面试重点）

默认扩容：

1.5倍

例如：

原容量：

```
10
```

扩容：

```
10 + 10/2

=15
```

源码：

```
newCapacity =
oldCapacity + (oldCapacity >> 1);
```

---

## 4. 添加元素

尾部添加：

```
list.add("A");
```

时间复杂度：

```
O(1)
```

中间插入：

```
list.add(2,"A");
```

需要移动元素：

```
O(n)
```

---

## 5. 删除元素

删除：

```
remove(2)
```

需要移动：

```
O(n)
```

## 6. ArrayList线程安全吗？

不是。

原因：

多个线程同时修改：

可能：

- 数据覆盖
- size错误

解决：

### 方法1

Collections.synchronizedList

```
List list =
Collections.synchronizedList(
new ArrayList<>()
);
```

### 方法2

CopyOnWriteArrayList
