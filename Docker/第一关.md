
## 安装Docker Desktop

首先安装 https://www.docker.com/products/docker-desktop/ ,安装时勾选WSL2。装完重启，打开 Docker Desktop，等左下角变成绿色 “Engine running”。

## 验证安装

```bash
docker --version

docker run hello-world
```

## docker常用命令

### 观察和操作这个容器
```shell
docker ps # 查看正在运行的容器
docker images # 查看本地镜像
docker logs my-nginx # 刷新几次浏览器，再看日志，会多出访问记录
```
---
```shell
docker exec -it my-nginx bash # 进入容器内部，像登陆了一台小Linux

ls /usr/share/nginx/html # nginx的网页文件在这
exit # 退出容器
```
### 停止和清理

```bash
docker stop my-nginx # 停止容器
docker ps -a # 能看到已停止的容器
docker start my-nginx # 重启容器
docker rm -f my-nginx # 删除容器
```
