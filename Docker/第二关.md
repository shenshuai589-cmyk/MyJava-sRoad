## 用容器跑Redis和MySQL，学数据卷

### 不使用数据卷

```shell
docker run -d --name my-redis -p 6379:6379 redis:7

docker exec -it my-redis redis-cli
```

---
```shell
set name chan
get name
exit
```

> 在redis-cli中新建变量

```shell
docker rm -f my-redis
docker run -d --name my-redis -p 6379:6379 redis:7
docker exec -it my-redis redis-cli get name

# 返回的是nil ,表示数据被删了，因为数据存在容器自己的"小房间"里，房间拆了，东西就没了
```


### 使用数据卷( -v)

```shell
docker rm -f my-redis
docker run -d --name my-redis -p 6379:6379 -v redis-data:/data redis:7 
# `-v redis-data:/data` 的意思是：**把容器里的 `/data` 目录，存到 Docker 管理的一个叫 `redis-data` 的"外部硬盘"里**。
docker exec -it my-redis redis-cli set name chan
docker stop my-redis
docker rm my-redis
docker run -d --name my-redis -p 6379:6379 -v redis-data:/data redis:7
docker exec -it my-redis redis-cli get name
# 这次就可以返回chan 
```



### 环境变量（- e）

```shell
docker run -d --name my-mysql -p 3306:3306 -e MYSQL_ROOT_PASSWORD=123456
-e MYSQL_DATABASE=demo -v mysql-data:/var/lib/mysql mysql:8.0
```

| 部分                            | 含义               |
| ----------------------------- | ---------------- |
| -e MSYQL_ROOT_PASSWORD=123456 | 设置root密码         |
| -e MYSQL_DATABASE=demo        | 启动时自动创建一个叫demo的库 |
| -v mysql-data:/var/lib/mysql  | MYSQL的数据目录存到数据卷里 |
