## 2.VO / DTO（Value Object / View Object）

**2.1什么是VO**
```
vo是视图对象，专门专门返回给前端的数据
```
**2.2为什么需要VO**
```json
数据库中的数据：
tb_user  
------------------  
id  
username  
password  
email

pojo对象中的数据：

public class User {  
	private Long id;  
	private String username;  
	private String password;  
	private String email;  
}
如果直接返回的话：
{  
	"id":1,  
	"username":"admin",  
	"password":"123456",  
	"email":"admin@qq.com"  
}
那么此时密码就会泄露，所以我们需要UserVo:用户视图对象

```
UserVO
```java
public class UserVO {  
	private Long id;  
	private String username;  
	private String email;  
}
```
返回结果：
```json
{  
	"id":1,  
	"username":"admin",  
	"email":"admin@qq.com"  
}
```

## 4.修改 xml映射文件

在 XML 中追加下面这段连表查询的 SQL。
```xml
<select id="selectStaffWithDept" resultType="UnderworldStaffVo">
	select
		s.id,
		s.username,
		s.real_name,
		s.status,
		s.dept_id,
		d.id,
		d.dept_name,
		d.loc
	from underworld_staff s
	left join underworld_dept d on s.dept_id = d.id
</select>
```

## 7.持久层（Mapper）登录验证

1.在mapper接口中新加登录验证方法
```java
/**
 * 根据账号和密码查询阴差（用于登录验证）
 */
UnderworldStaff selectByLogin(@Param("username") String username, @Param("password") String password);
```
2.修改 `UnderworldStaffMapper.xml`
```xml
<select id="selectByLogin" resultType="UnderworldStaff">
	SELECT id, username, real_name, dept_id, status
	FROM underworld_staff
	WHERE username = #{username} AND password = #{password}
</select>
```
3.修改 `UnderworldStaffService.java` 接口
```java
/** 
* 阴差登录校验 
* @return 登录成功返回阴差完整信息，失败返回 null 
*/ 
UnderworldStaff login(String username, String password);
```
4.修改 `UnderworldStaffServiceImpl.java` 实现类
```java
@Override 
public UnderworldStaff login(String username, String password) { 
// 直接调用 Mapper 去数据库里撞运气 
return staffMapper.selectByLogin(username, password); 
}
```
5.controller修改
在 `UnderworldStaffController.java` 中追加：
```java
/**  
 * 真正的高安全登录接口  
 * 路径：POST http://localhost:8080/staff/login  
 */@PostMapping("/login")  
public Result<UnderworldStaff> login(@RequestBody UnderworldStaff loginParam) {  
  
    // // 1. 调用 Service 去数据库核对  
    UnderworldStaff staff = staffService.login(loginParam.getUsername(), loginParam.getPassword());  
  
    // 2.根据数据库返回结果进行严密判断  
    if (staff == null) {  
        return Result.error("登入失败：该账号未在生死簿登记，或通关口令错误！");  
    }  
    // 3. 查出来了，说明密码正确，把这位阴差的资料（不含密码）打包返回给前端  
    return Result.success(staff);  
}
```
