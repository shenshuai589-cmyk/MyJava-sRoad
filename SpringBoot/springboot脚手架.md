### 1.什么是脚手架
一种可以快速生成SpringBoot项目结构的工具，避免了手动创建目录、配置Maven、导入依赖等重复工作。

### 2.生成后的目录结构
```xml

springboot-demo
│
├── src
│   ├── main
│   │   ├── java
│   │   │   └── com.example
│   │   │       └── SpringbootDemoApplication.java
│   │   │
│   │   └── resources
│   │       ├── application.yml
│   │       ├── static
│   │       └── templates
│   │
│   └── test
│
└── pom.xml

```
