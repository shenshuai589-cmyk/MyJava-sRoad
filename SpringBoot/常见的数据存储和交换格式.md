
## 一、什么是数据存储和交换格式

不同系统之间需要传递数据。

例如：

```text
浏览器  ←→  SpringBoot
SpringBoot ←→ 第三方接口
Java程序 ←→ 配置文件
```

数据在传输过程中需要按照一定格式组织。

这些格式就称为：

```text
数据存储格式
数据交换格式
```

---

# 二、XML

## 什么是 XML

XML（Extensible Markup Language）

可扩展标记语言。

格式：

```xml
<user>
    <name>张三</name>
    <age>20</age>
</user>
```

---

## 特点

优点：

```text
结构清晰
可读性强
支持复杂层级
```

缺点：

```text
标签多
冗余大
解析效率较低
```

---

## 典型应用

Spring早期：

```xml
<bean id="userService"
      class="com.powernode.service.UserService"/>
```

MyBatis：

```xml
<mapper namespace="UserMapper">
</mapper>
```

Maven：

```xml
<project>
</project>
```

---

# 三、JSON（最重要）

## 什么是 JSON

JavaScript Object Notation

轻量级数据交换格式。

格式：

```json
{
  "name":"张三",
  "age":20
}
```

---

## 对象

```json
{
  "id":1,
  "name":"Tom"
}
```

---

## 数组

```json
[
  {
    "id":1,
    "name":"Tom"
  },
  {
    "id":2,
    "name":"Jerry"
  }
]
```

---

## 优点

```text
简洁
体积小
解析快
跨语言支持好
```

---

## SpringBoot中最常用

Controller：

```java
@RestController
public class UserController {

    @GetMapping("/user")
    public User getUser() {
        return new User(1L,"Tom");
    }

}
```

返回：

```json
{
  "id":1,
  "name":"Tom"
}
```

Spring Boot 默认使用 Jackson 自动完成：

```text
Java对象
↓
JSON
```

转换。

# 四、YAML（SpringBoot重点）

## 什么是 YAML

YAML Ain't Markup Language

一种配置文件格式。

---

## 写法

```yaml
server:
  port: 8080

user:
  name: zhangsan
  age: 20
```

---

## 特点

优点：

```text
简洁
层级清晰
可读性高
```

缺点：

```text
缩进要求严格
```

---

## SpringBoot配置

```yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/test
    username: root
    password: 123456
```

---

# 六、CSV

## 什么是 CSV

Comma-Separated Values

逗号分隔值文件。

格式：

```csv
id,name,age
1,Tom,20
2,Jerry,18
```

---

## 特点

优点：

```text
简单
体积小
Excel直接支持
```

缺点：

```text
不支持复杂嵌套结构
```

---

## 应用场景

```text
Excel导入导出
报表
数据迁移
```

## XML和JSON区别

### XML

```text
标签形式
结构复杂
体积较大
```

### JSON

```text
键值对形式
简洁
解析速度快
```

```text

```

# 九、总结

|格式|用途|特点|
|---|---|---|
|XML|配置、数据交换|结构清晰但冗长|
|JSON|前后端数据交换|最常用|
|YAML|SpringBoot配置|简洁易读|
|Properties|Java配置文件|简单传统|
|CSV|Excel、报表|轻量|
|SQL表|数据持久化|数据库存储|

---

## 一句话总结

```text
Java后端开发最常见的格式：

配置文件：
YAML、Properties

接口数据：
JSON

框架配置：
XML

报表导出：
CSV

数据库存储：
MySQL表结构
```
